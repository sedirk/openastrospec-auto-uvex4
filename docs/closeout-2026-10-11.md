## 1. 序列与收口

- [ADR-0025](adr/0025-reusable-night-clock-deadlines.md)：序列按夜间钟点重复使用，
  运行开始才解析为不可变截止时刻；跨午夜不依赖过期的日历日期，也不靠重试续发预算。
- 每目标独立编辑身份、坐标、曝光计划、恢复与一次性 PHD2 强制校准选项；夜间容器
  管理夜间窗口、天气、结束策略。开始处的显式卡片连接安全监视器并选择真实模式，
  不把“保存了模板”当作已经获得安全或设备动作许可。
- [ADR-0026](adr/0026-protected-standby-after-target-failure.md)：单次运行的关顶偏好
  与整夜序列收口分开；序列可声明终端收口卡片。普通结束保持开顶时进入受保护待机，
  不偷偷在目标失败清理时关顶，也不把未关顶状态当作整夜已完成。
- Unsafe、安全证明丢失、晨光、截止与显式结束仍走已检查的安全收口；用户取消不
  冒充机械收口。无干涉屋顶配置也不豁免独立停止和读回要求。
- [ADR-0027](adr/0027-terminal-target-guide-state-retirement.md)：目标终止且独立证明
  采集、导星和运动已停止后，归档旧导星恢复入口、清理目标局部状态，下一目标重新取场。
  原账本、文件与哈希保留；归档不是回位成功。同一目标重试、暂停与翻转不借此更新预算。

对应[原生序列操作说明](native-spectroscopy-night-sequence.md)、
[多目标模板说明](spectroscopy-multi-target-template.md)及 `config/sequences/` 已同步。
真实台站的目标清单、Profile、有效配置与运行文件仍为本机数据，不纳入源码提交。

## 2. 导星、邻场与科学质量

- [ADR-0028](adr/0028-advisory-measured-guide-residual.md)和
  [ADR-0029](adr/0029-measured-post-lock-continuation.md)分离精度偏好、PHD2 原生 settle
  与新帧实测资格。原生超时不能伪装成功，但可由同一会话的新帧判断是否具备继续修正
  或已有授权的试拍条件；真实丢星、无修正输出、身份或所有权改变不因此放行。
- 修复恢复取帧的 owner/停止回执误判，恢复检测使用原生单帧接口；导星前根据 PHD2
  原生选星 SNR 作有界曝光优化，保留失星回档与原预算，不自行替换 PHD2 校准系数。
- [ADR-0030](adr/0030-exploratory-neighbour-field-continuity.md)允许使用邻场 WCS、
  实测位移、新像素证据及适用的本轮双镜映射提示继续探索；区分预测与测量、局部搜索
  半径与原点预算。不会仅为重复获得整幅解算而丢弃已有位置连续性，也不无限扩大搜索。
- [ADR-0031](adr/0031-independent-science-quality-and-target-outcomes.md)修复完整安全链
  错误禁用已保存 warning 试拍选项的问题。科学质量同意独立于弱监督模式，完整天气、
  身份、运动和停止安全链不变；新 Profile 仍默认严格。
- 一次滚动更新只取得一张新帧，再验证完整三帧窗口，不再对强制三帧的结果调用
  `Single()`，也不只挑最后一张好帧。光学失败中断连续性后，在原期限内重新取完整窗口。
- 从发生点保留目标级质量失败类型和原错误码；原生序列实际执行双目标测试，确认已
  停止清理后按保存策略跳过。未知异常、安全/设备故障、停止未确认、取消和 EndNight
  仍非兜底跳过条件；通知区分“本目标失败/跳过”和“整夜停止”。

逐轮故障、证据与安装细节保留在 `reports/2026-10-10-*.md`、
`reports/2026-10-11-*.md`，集中问题对照见
[科学质量与窗口回归报告](reports/2026-10-11-science-quality-and-window-regression.md)。

## 3. 单一生产路线与职责重构

单次按钮与原生序列共用配置、canonical plan、runner factory 和 host，没有维护两套
独立观测算法。[代码审计](reports/2026-10-11-code-audit-and-deduplication.md)删除重复
commissioning 契约、不可达旧策略并合并实际重复逻辑，保持已发布 JSON 兼容。

| 实际流程 | 唯一负责的决策或状态 |
| --- | --- |
| G3 取场 | 重取场前核对未结回程，选择接受、粗定位或有界邻场搜索 |
| G3 回程 | 原持久化路径与预扣、到位和稳定读回，不重新发放运动预算 |
| PHD2 入缝收敛 | 同会话新帧窗口、精调循环、移锁意图与残差，不曝光 ATR |
| ATR 试拍 | 曝光档位、过曝回退/弱信号延长、选档及重试拍状态 |
| ATR 科学采集 | 尝试/留存/接受/警告帧与积分、最终试拍只复用一次 |

有限接口接回原设备 owner、即时安全门和证据服务；没有新建第二套设备客户端。
runner 的既有计数字段变为只读投影，而不是保留两份可漂移状态。

量化口径详见[重构报告](reports/2026-10-11-observation-workflow-boundaries.md)：
.276 审计相对其开始工作区净减 1,094 行生产 C#；.277 的职责提取使 runner 合计减少
1,415 行，但接口/适配器令生产总量净增 503 行。两项分别统计，不把本次远端 diff
冒称本轮净精简。WCS/邻场低层、初始导星准备和跨阶段恢复仍在共享 runner，后续债务保留。
