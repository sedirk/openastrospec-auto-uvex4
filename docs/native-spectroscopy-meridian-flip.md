# 光谱中天翻转（0.4.0.213，已安装，待真实翻转验收）

本次扩展 ADR-0019 中预留的翻转衔接，不改变设备所有权、冻结设计记录或现场配置。
2026-09-21 已安装并重启 N.I.N.A.，确认运行版本为 .213、原生高级序列指令列表包含专用翻转触发器。
安装检查未连接设备、启动曝光或翻转；真实翻转续拍仍待现场分阶段验收，不能把离线测试或菜单加载当作天空验收。

## 怎样放进高级序列

1. 使用 `OpenAstroSpec · 光谱整夜序列`，将 `UVEX4 目标观测`放在里面。
2. 添加 **`OpenAstroSpec · 光谱中天翻转`**。可以放在全局、整夜容器或单个目标；
   同一个目标只能继承一个，不要全局和局部重复添加。
3. 在 N.I.N.A. 原生翻转设置中启用镜筒侧检查，设置最早/最晚翻转时机和提前暂停时间。
   赤道仪须真实报告镜筒侧、跟踪和中天时间；未知状态不自动猜测。
4. 专用触发器的额外保存/导星余量默认 120 秒，可设 30–900 秒。
   调度还会加上当前配置中最长的测光滤镜曝光时长，等待测光所有者保存当前帧。
5. 不在同一作用域混用普通翻转、dither、自动对焦触发器。专用光谱触发器不执行普通深空目标；
   混合深空/光谱项目请放到不同原生分组，各自放合适的触发器。

专用翻转仅支持完整安全链下的真实整夜容器，不支持有人弱监督/独立单目标直接翻转。
目标内部不再叠加循环条件，使用合格科学帧数、最多尝试数及整夜截止/晨光条件。
模拟序列仍完全不接触设备；真实翻转首次使用必须有人监督并完成分阶段验收。

## 实际执行顺序

每次试拍/科学帧开始前，用原生时机算法评估“下一张曝光 + 最长测光帧 + 额外余量”。
导星窗口等待后、真正打开 ATR 曝光前再检查一次，避免前面的等待耗尽翻转余量。
已开始的正常长曝先保存；安全事件仍立即中断。完成全部科学帧后不会为了翻转而多跑一段。

需要翻转时：

1. 当前段返回明确的 `NATIVE_MERIDIAN_SEGMENT_BOUNDARY`，不再开新帧；这不是整个目标完成。
2. QHY 由原 worker 协作暂停，保存当前帧并完成焦位读回后才结束作业；停止 PHD2。
   核验 ATR、测光作业、赤道仪空闲以及旧运动账本已结清。旧预算/回程责任没有清零。
3. 整夜容器一直持有设备排他执行权。先落控制记录，再使用原生时机等待及原生赤道仪翻转接口，
   不调用 ATR 星场居中、不额外启动自动对焦、不动屋顶/镜盖。
4. 原生命令最多发一次，须返回成功，确认新的镜筒侧、停止运动、恢复跟踪；有旋转圆顶时须已有
   N.I.N.A. 跟随并完成同步。失败、取消、断连和不确定结果都不自动重试翻转。
5. 新建同一目标的下一段，重新运行同一生产十一阶段。旧 WCS、光学目标定位、狭缝缓存、
   锁点、导星 epoch 和预曝光凭据都不会从上一 runner 带过去。新段须重新满足现有身份、
   镜筒侧/标定、G3 定位、测缝、入缝、导星、温度、试拍和科学质量门才可续拍。

每目标最多一次翻转、两段运行。翻转后的新入缝属于显式、有限的新运动阶段，原段的运动账本
留在原 run ID 下，不把老的已用次数改成零，也不把未结清的回程责任转成“成功”。
普通失败重试仍使用各自既有预算；不能借翻转扩展成无限恢复。
目标级取消覆盖曝光段之间的等待/翻转，明确通知整夜容器这是普通取消，不启动机械收口。
翻转记录未确认会阻止下一目标，但不替代物理设备空闲检查；安全事件下，原所有者退出且设备
停止已确认后，仍可由既有整夜安全链执行受控收口。

## 帧数与证据

目标原始合格帧目标、最多尝试、已接受张数/积分和已复用试拍都跨段累计。
例如原计划 5 张、最多 8 次，翻转前接受 2 张并用了 3 次，翻转后只分配 3 张和 5 次。
末次合格试拍仍可计入科学帧，但原始 FITS 不复制、不重写、不重复计入。
若临开快门前的第二次检查截住已记账的尝试，该尝试仍保留；不会因翻转退款或制造额外次数。

每段有独立原始 manifest，其帧计数是该段本地值；进度显示是整个目标累计值。
manifest 标签记录 `nativeTargetRootRunId`、原始目标计划、此前分段 ID 和累计计数，
避免把两段误当成两个互不相关的目标，或把累计计数当成本段新拍摄量。

当前翻转控制记录：`%LOCALAPPDATA%\UVEX-ADV\observations\control\native-meridian-flip.json`。
若进程在等待/命令期间中断，或记录损坏，下一轮会报告 `NATIVE_FLIP_UNCONFIRMED` /
`NATIVE_FLIP_JOURNAL_UNREADABLE`，不会重新发翻转。须通过现场只读状态与原始日志确认，
人工处理遗留状态；本版没有自动“清掉记录继续”的按钮。成功只记录 `MountVerified`，
它表示机械端确认，不等于入缝或科学质量通过。各段 FITS、manifest 和审计证据不变。
