# 原生高级序列 · 光谱整夜流程（第一版）

## 逐目标导星恢复（0.4.0.260）

每张目标卡保存“本目标导星自动恢复”（默认开启）与“星点等待上限”（默认 300 秒，
可调 30–600 秒）。新卡默认质量失败停止确认后跳过；旧序列明确保存的“结束本夜”不自动改写。
这两个恢复字段未写入旧模板时采用默认值，不从别的目标继承编辑值。

遇到已审核的实际丢星、初始稳定或光学窗口失败，先确认本轮导星已停止且运动责任结清。
弱星场原地检测新帧并等待，不改锁点或发校准脉冲；连续两张可用星场后重新取目标/狭缝证据并重选星。
重选后仍发生符合条件的导星故障，才向 PHD2 请求一次强制校准，随后再次定位、入缝。
每目标最多一次重选恢复和一次校准，总恢复会话 900 秒；显式起始校准或已观察到的原生校准
消耗同一校准额度，翻转不重置。等待不刷新原运动、回程、科学帧和截止预算。

恢复用尽后按本目标失败策略处理，跳过前由整夜容器独立检查空闲及运动结算；设备断连、
输出失败、身份改变、未知异常和未结回程不走普通丢星恢复。等待不证实天气原因，也不授权忽略
AIWeather Unsafe、晨光或截止；恢复代码不单独开关顶。详见 [ADR-0024](adr/0024-bounded-adaptive-guiding-recovery.md)。

## 测试夜保持开顶与初始导星（0.4.0.253）

整夜容器新增“测试结束保持开顶，关顶收口单独操作”，默认关闭。启用时必须填写含时区的截止时间。
全部目标完成或经停止确认后质量跳过时，容器进入 `TestStandby`，不立即关盖/关顶、Home 或 Park，
不启动新曝光。它仍持有同一整夜占用和 AIWeather 安全订阅，**不是退出序列后放任屋顶开启**。
操作者可单独点击“关顶与整夜收口”；截止、晨光、Unsafe 仍走原有安全收口。设备/未知故障不会
转为质量跳过或保持开顶。普通取消仍不发机械命令；取消后必须由操作者负责台站状态。
保持开顶等待尚未结束时不能另开一条竞争设备的观测；需要重测时先明确取消并核对空闲，再重新加载序列。

同一容器保存初始导星半径/持续时间/超时；半径 0 表示沿用 Profile，范围 0–5 px，持续 1–30 s，
超时 30–300 s。本次现场测试使用 3 px / 5 s / 180 s，仅用于初次 `guide` 稳定，不改变入缝残差、
回程、丢星、校准或设备输出门。修改在下一次启动生效，活动夜锁定快照不热改共享 Profile。

初次稳定失败若具有同连接/操作/epoch 的终态、足够且无丢失的导星帧、有效输出和原生锁点归属，
并且从未开始精确锁点移动，可确认停止后报告 `PHD2_INITIAL_SETTLE_NOT_REACHED`。
只有外层再次证明采集空闲、运动账本结清且目标选择“质量失败后跳过”时才继续下一目标。
`PHD2_SLIT_PLACEMENT_FAILED_SAFE`、设备输出失败、丢星、未确认停止及未知异常仍不在跳过名单。
`.255` 同样区分初始 settle 已通过、随后首个光学窗口未通过的情况：仅在尚无精调历史、

不把一次目标质量失败当作整夜故障关顶。内部 `PHD2_GUIDE_WINDOW_NOT_STABLE` 文本本身
没有跳过权限；精调后的失败仍要保留回程责任。
模拟/native 序列测试覆盖跳过、停止失败、显式结束、截止、Unsafe、普通取消与等待期间占用未释放。

自动警告继续精调，不要求手动恢复，也不表示目标已入缝。上限一致传到后续资格/规划；
实际目标到狭缝残差、精确锁点读回、运动/回程预算、丢星与输出/安全门保持原值。
移锁后的 native settle 仍必须真实成功，最多 3 px / 5 秒稳定，且不能占满后续新帧预算。
原 `.255` 的质量跳过在四组仍不通过时作为后续路径。见

## 与深空目标指令集的对应关系

开关顶已经由整夜容器的共享 runner 管理，不需要另外插入原生开关顶指令。
默认先 Park 再开关顶；仅导入本台站已确认且哈希绑定的无干涉屋顶方案后，开顶不再
要求 Park，结束/Unsafe 则先停止采集与运动、关顶，再单独尝试 Park。关顶成功与
停放失败分别保存，不能把“顶已关”写成整夜全部成功。普通取消仍不发机械收口。
详见 [ADR-0021](adr/0021-station-attested-noninterfering-roof.md)。

0.4.0.249 补齐无干涉模式的开顶准备：完整安全链、锁定身份、空闲采集及 PHD2 停止
检查通过后，若赤道仪只剩跟踪开启，通过主 N.I.N.A. 最多关闭一次跟踪，10 秒内
取得两次身份匹配的无 Slew、无导星脉冲、跟踪关闭读回，再复核安全及导星状态后
发开顶。跟踪设置的返回值不替代读回；正在转动或导星时不会擅自 StopSlew、Home
或 Park。失败保存具体状态及是否请求关闭跟踪，尚未发出开顶命令。

**重试整夜与继续未结束的序列不同。** 整夜已 Terminal、原生项目已 FINISHED 时，
再次点播放不会重跑已完成项目，也不会再次开顶。先确认采集、运动及收口均已停止，
在高级序列重置执行状态，或重新加载同一序列文件，再检查目标、剩余夜长与截止时间
后启动。不要通过清运行账本、重启或手动开顶掩盖尚未结清的回程/停放责任；程序也
不会偷偷把 FINISHED 项重置成新一夜。

`UVEX4 目标观测` 是一个目标的完整光谱流程，角色类似原生“深空目标指令集”，
并实现 N.I.N.A. 的 `IDeepSkyObjectContainer` 目标接口；但内部是固定的十一阶段，
不是任意插入深空曝光指令就具有全部深空功能的通用容器。
外层 `光谱整夜序列` 才负责多个目标的顺序、截止、失败跳过和统一收口。
“本目标失败策略”作用于当前目标在整夜容器内失败后的处置，不决定定位分支；
单独执行该目标时仍是失败暂停。两项是“结束本夜并收口”和“质量失败且停止确认后跳过”。

0.4.0.250 区分“当前已触及地平线”与“当前可见但剩余完整保护窗口不足”。后者在阶段
内部或交接检查点保留为 `TARGET_VISIBILITY_WINDOW_EXHAUSTED`，不再包装成未知阶段异常；
选中跳过策略、确认设备停止且没有未结运动后，结束当前目标并独立检查下一目标。
不会因此降低地平线、继续当前目标或延长整夜截止时间；当前越界、未知异常和停止失败仍

## 如何使用

### 在每张目标卡片内编辑（0.4.0.259）

展开高级序列中需要修改的 **UVEX4 目标观测** 卡片，直接编辑该目标；不再在整夜顶部
用下拉框选择目标。每张卡片独立显示名称、J2000 赤经（时/分/秒）、赤纬（度/分/秒）、
目标高度图、合格帧数、固定曝光秒数、最多尝试、可见窗口预算、强制校准开关和失败策略。
目标身份区可折叠，光谱采集和强制校准仍在本目标内；不用展开内部十一阶段。
复制、删除、上下移动仍使用 N.I.N.A. 原生容器操作，编辑后用原生保存按钮保存序列。
不修改共享 Profile；运行中先停止整个序列，不能热改活动目标。

交互参考 [N.I.N.A. 官方高级序列说明](https://nighttime-imaging.eu/docs/master/site/sequencer/advanced/advanced/)
及本机对应版本的 `DeepSkyObjectContainer`、原生坐标模板和层级容器视图。复用原生
`InputCoordinates`、坐标校验、折叠控件和高度图；按目标分层编辑，而非在整夜容器再造一个目标表单。
这不改变光谱目标内部的固定十一阶段，也不表示可混入普通主相机曝光或普通翻转来代替光谱流程。

**`2×120s` 是两张合格的 120 秒 ATR 光谱，不是每个目标后额外等待 240 秒。**
合格试拍可计入两张，失败帧不计入；定位、制冷、导星、读出、重试另耗时。
将帧数改成 3、曝光改成 300，摘要随之显示 `3 × 300 s`；生成器的目标标题也同步更新。
曝光填 0 表示沿用自动探针选档。不要只改容器标题；自定义标题只是标签。

替换目标可以直接填写名称及坐标，也可以把右侧“目标”中的已保存目标拖到本目标身份区，
或点击“从星图读取”导入配置的星图软件当前所选目标。名称输入不自动查星；“发送到构图助手”
只打开规划视图，不执行指向、居中或曝光。赤经直接输入时分秒，赤纬保留负零度的小数角度。
拖入和星图导入只替换本目标身份，不覆盖其曝光、导星或失败选项，更不会修改其它目标。
名称或坐标变化会清除旧目标目录资料，避免继承旧目标的星等/分类身份。
改完还须检查新目标的可见窗口，不能认为旧目标的预算仍然合适。

每个目标的 **本目标开始时强制 PHD2 校准一次** 默认关闭。打开后，在该目标首次无未结
精调责任的导星边界，请求 PHD2 重新校准；完成后重新取场、确认狭缝，再进入精调。
这是会产生运动的选项，不是在编辑或加载模板时立即执行。失败/恢复/翻转续拍不重复
强制校准；PHD2 仍是唯一校准管理者，不恢复旧的重复数值硬门。详见 [ADR-0023](adr/0023-explicit-per-target-phd2-calibration.md)。

整夜容器只保留全夜摘要与默认折叠的 **夜间设置**，包含截止、晨光、初始导星稳定等待、
Home/Park 和保持开顶设置；不再显示任何单目标参数或强制校准开关。
此次编辑界面不改变天气、安全收口、目标间屋顶状态或既有失败跳过策略。

已有可直接导入的[三目标光谱序列模板与填写说明](spectroscopy-multi-target-template.md)
（2026-10-09，按 N.I.N.A. 3.2 / 插件 .240 验证）。提供整份序列和可拖入模板两种文件，
默认模拟，目标名称/坐标待填写；不修改台站绑定或自动切换安全链。

在 N.I.N.A. **高级序列**的 `OpenAstroSpec Auto` 分类中添加
`OpenAstroSpec · 光谱整夜序列`，再将多个 `UVEX4 目标观测`放入该容器。
可直接使用 N.I.N.A. 的拖放、复制、排序、目标坐标编辑和模板保存；不是另一套调度器。
也可从高级序列右上角 `+ → 指令集 → OpenAstroSpec Auto` 添加整夜容器，
再从容器内部“指令集”行右侧的 `+` 添加 `UVEX4 目标观测`。
每个目标保留原生十一阶段子项，复用与自动观测面板相同的生产编排器、设备工厂、定位、
入缝、探针和科学质量门。运行期间阶段状态由原生序列维护，后台不能提前改变下一子项状态。

每个目标独立保存：目录 J2000 坐标、定位策略、合格科学帧数、最多尝试数、固定曝光秒数
（0 表示原来的自动探针选档）、失败策略。固定曝光仍须通过探针与科学质量门，不代表跳过检测。
目标参数形成不可变运行配置并记入该轮 manifest，不改写全局 Profile；重用合格末次探针的规则不变。

夜间容器提供晨光太阳高度（默认 −12°）及可选 ISO-8601 截止时间，时间须包含时区。
这些夜间条件在本夜启动时锁定，阶段边界及已保存科学帧之间检查：普通截止不切掉正在执行的长曝。
安全监测事件则立即要求停止，独立于普通截止。

### 截止时间保存与开关顶显示（0.4.0.241）

N.I.N.A. 3.2 原生序列加载器会先把 ISO 日期文本解析成日期 token。旧版字符串字段随后
变成不带时区的本地化文本，导致已填写 `+08:00` 的截止时间在启动时被拒绝。现在专用
转换器保留同一绝对时刻，原生加载、保存、再次加载均继续带时区；真正缺时区或格式错误
的输入仍拒绝，不从机器时区猜测。此前测试只覆盖空截止时间，现补非空、多偏移与无效
时间的原生 round-trip 回归。修复后应重新加载原带时区序列，不能把已丢时区的旧文本
自动追认为有效，也不能把 N.I.N.A. 已失败子项的再次跳过当作重试成功。

开关顶不是单独的一套控制路径：默认 Park 联锁下，首目标的 Night Setup 经完整安全链核验后，执行
`确认 Park → 开顶并回读 → 开镜盖`；整夜容器最后执行
`停止采集/导星 → 关镜盖 → Park 并回读 → 关顶并回读`。
两条顺序已直接显示在整夜序列编辑器中。不要再额外叠加无条件 Open/Close Shutter，
避免绕过天气/停放前置条件或在目标之间重复关顶。普通取消仍不授予机械收口动作。
0.4.0.242 的已确认无干涉台站采用本文开头所述的独立关顶顺序，不再要求开顶前 Park。

## 目标间与整夜结束

每个目标结束先停止并核对 ATR/PHD2/并行测光状态，不在目标之间反复关盖、关顶。
整个夜间容器持续持有同一个观测排他锁，目标间隙也不允许面板另开一轮或主镜对焦。

整夜完成、截止，或明确点击**结束本夜并收口**后，先等待当前目标任务退出及停止确认。
默认生产收口为：关平场板/镜盖 → 赤道仪已标定停放位 → 确认停放且停止 → 关顶并回读。
ADR-0021 已确认无干涉模式保留镜盖收口，但屋顶先于独立 Park 关闭并确认；Park 失败仍报错。
任何断连、身份不符、运动未停或终态未确认都不能显示收口成功。
**停放不等于机械 Home。** 默认模式须现场确认已保存的 Park 姿态允许关顶；无干涉模式则须确认
所有姿态均允许关顶，不能把 Home 或失败的 Park 当作这项确认。

## 失败策略与边界

0.4.0.248 起，整夜中的目标若选择“质量失败且停止确认后跳过”，会在创建目标 runner
和任何设备动作之前，以当前时刻及原定时长检查高度窗口。有效计划若仅因该窗口低于
原高度要求而不适合，记录 `SkippedPreflightHorizon / HORIZON_BLOCKED` 并继续下一目标；
日志保留原计划和最低高度，不缩短曝光、不降低地平线、不连接相机来证明一次并未发生的
曝光已停止。此分支不发布观测成功，也不改变上一目标的停止确认或旧运动账本。
截止/晨光、取消、安全变化、无效计划、配置变化仍停止；开始设备流程后的高度失败
不属于这个跳过分支。独立单目标和“结束本夜并收口”策略保持原行为。

默认“结束本夜并收口”。可选“质量失败且停止确认后跳过”，但只允许明确质量错误代码，
且必须确认采集空闲、原运动回程账本已结清。当前允许：

- `G3_CATALOG_SHORT_POSITION_UNCONFIRMED`
- `G3_POST_WCS_SHORT_UNCONFIRMED`
- `G3_POST_WCS_SHORT_HANDOFF_OUTSIDE`
- `G3_BOUNDED_SEARCH_EXHAUSTED_RETURNED`
- `G3_POST_WCS_TARGET_NOT_MEASURED`
- `ATR_ATTEMPT_LIMIT`
- `ATR_PROBE_ATTEMPT_LIMIT`

设备丢失、身份不符、安全事件、导星取帧超时、写盘失败、未知异常与未完成回程不自动跳过。
失败目标的原始 FITS、manifest 和失败代码保留，跳过不改写为科学成功。
各目标 run ID、结果、原始 manifest 路径、停止检查及整夜收口结果写入
`%LOCALAPPDATA%\UVEX-ADV\nights\night-*.json`。这些是本机运行证据，不进入 Git。

真实整夜模式必须有完整安全链、选定屋顶和镜盖设备，并启用结束关盖/关顶。
**有人弱监督 Profile 不能直接启动自动关顶整夜任务**；原单目标有人模式仍保留。
安装不会替用户切换监督方式或声称设备已经完成无人值守验收。

第一版只接受顺序 UVEX 目标，不允许混合模拟/真实目标。准备动作放在整夜容器之前。
允许在目标、整夜容器或其上层挂载一个专用光谱翻转触发器；全局与局部重复挂载会被拒绝。
普通中天翻转、dither、自动对焦等触发器仍不支持穿透光谱目标。
启用翻转时目标内不要再加循环条件，以免分段重启循环计数；使用科学帧数和整夜截止/晨光条件。

现有目标内有界重试保留。实际多目标、晨光与安全故障收口仍须分阶段实机验收。

## 0.4.0.243：目标失败跳过与整夜收尾边界

原生整夜序列仍由 N.I.N.A. `SequentialStrategy` 驱动。单目标质量失败不等于目标完成：
保留其失败 manifest，等待协调器持久化结束、采集停止及运动责任结清后，才记录
