## 修复

- 从 N.I.N.A. 已配置的 Stellarium 端点只读一次所选对象详情；要求名称与锁定 HIP ID
  精确一致、坐标一致到 5 角秒内、明确双星、WDS 记录在最近 10 年内，间距为 3–30 角秒。
- 固定该记录及响应 SHA-256；用本轮正式 WCS 投影得到**有方向的主星→伴星向量**。
- 仅当短帧恰有两个独立、未饱和、通过原轮廓门的候选，且唯一有序配对的向量残差
  不超过 3 px 时，测量主星位置。反向配对、仅有相同间距、选最亮、选离 WCS 最近的星，
  均不能代替这个检查。更多候选仍不自动选星。
- 首帧不授权继续。仍须独立新帧复核，保留原 3 帧上限、4 px 重复性检查、原识别窗口、
  WCS/赤道仪读回绑定和运动预算。伴星记录不会启动任何设备或扩大运动范围。
- 星图不可达、目标已切换、目录分量有后缀、旧数据或几何不匹配时，不替换原歧义判定。
- 这是短曝光粗定位的伴星关联，不是双星轨道拟合、不适用于任意混叠星、不把主伴星
  合并为一个质心，也不宣称精确入缝或最佳焦点。后续入缝仍要求新帧证据。
