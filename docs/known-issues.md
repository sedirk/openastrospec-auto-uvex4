# Known issues

## OBS-020 — PHD2 selection-loop configuration event cleared calibration attestation before guide

- **Observed:** 2026-08-30 on the live G3 slit-placement route. Calibration passed the initial policy check, but the subsequent full-frame selection loop/exposure transition emitted a PHD2 `ConfigurationChange`. The client correctly invalidated its cached calibration attestation; `GuideAndSettleAsync` then saw a null attestation and stopped with “guiding is blocked until calibration has passed the sanity gate.” The outer recovery fence did not classify this as LostLock/disconnect and paused the observation.
- **Cause:** the coordinator validated calibration before acquiring/selecting the guide frame, but did not refresh that validation after the selection loop and immediately before the guide RPC.
- **Resolution:** both commissioned PHD2 guide-entry paths now re-read the actual calibration after selection-loop configuration changes and immediately before guide. A valid readback continues normally. A genuinely invalid readback enters the existing single bounded forced-recalibration path; after recalibration, all pre-calibration G3 geometry is discarded and freshly reacquired. If the refreshed calibration remains invalid after that one cycle, guiding is checked-stopped and the run pauses without another command.
- **Status:** included in locally installed plugin `0.4.0.80`; live production-panel replay pending.

## OBS-021 — Recoverable inner-stage, G3/PHD2 and finalization faults ended in terminal dead ends

- **Observed:** repeated 2026-08-29/30 production-panel runs paused on disposable G3 binding/target evidence, transient PHD2 lock readback, locally advanced guide epochs, calibration cache invalidation, transient G3 capture/solver failures and optional-QHY finalization readback. Several failures occurred inside a dependency-rebuild chain or before required cleanup, so they bypassed the intended bounded recovery path.
- **Cause:** recovery allowances were local action counters rather than exact stage/code decisions, nested dependency failures returned directly, and a few device/solver calls still escaped as generic `STAGE_EXCEPTION`. PHD2 also advanced its own `GuideEpoch` at exact-lock/operation-bound settle boundaries without rebinding the durable pending record. Finalization read optional QHY state before isolating that failure from required UVEX/PHD2/cover/roof cleanup.
- **Resolution:** plugin `0.4.0.80` includes the whitelist-only `(stage, code, action)` supervisor introduced in `0.4.0.79`, with exact limits and an eight-attempt session fuse; nested failures re-enter that supervisor. Disposable G3 evidence/cloud/PL3-transient failures use bounded fresh immutable evidence without motion authority, while placement can rebuild a stale G3 binding once. PHD2 uses bounded same-epoch read-only lock queries, preserves charged budgets while replanning pre-dispatch drift, and rebinds only locally attested monotonic guide epochs. A successful native `find_star` null result now consumes the existing four-frame fresh-selection budget without swallowing RPC/connection/protocol errors. A runtime lock freshly verified back at its durable origin can rebuild G3/placement once under the same charged ledger; an unconfirmed checked-stop is retried once without guide/lock/mount mutation. Optional QHY finalization readback retries twice, then warns while required cleanup continues. Safety, identity, hashes, topology, ambiguous commands, durable debt and exhausted budgets remain hard stops.
- **Status:** fixed and locally installed as plugin `0.4.0.80`; offline fault injection and full solution verification completed on 2026-08-30. N.I.N.A. load verification and live production-panel replay remain pending because installation deliberately did not start N.I.N.A. or connect equipment.
- **Details:** [automatic-recovery dead-end audit](automatic-recovery-dead-end-audit-2026-08-30.md) and [automatic-recovery matrix](automatic-recovery-matrix-2026-08-29.md).

manifest/evidence references. Never attach credentials, private network URLs, raw
