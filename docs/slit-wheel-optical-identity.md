# UVEX 狭缝轮光学身份复核

UVEX 控制器回报的轮位是机械序号，不是物理狭缝宽度的独立证明。轮盘重装、标签贴错、固件序号与实物顺序不一致时，单独核对“位置 2”仍可能把错误狭缝用于自动观测。

正式流程因此取得同一无运动状态下的短、长两组 G3 `OFF×3 → ON×3 → OFF×3` 狭缝照明序列，并同时用于两件事：

1. 用短曝光定位上侧强反光边，用允许该反光边过曝的长曝光确认下方黑色、不反光狭缝区及第二物理边；物理缝宽是两边之间的距离，入缝中心是两边中点；
2. 将 fresh 暗孔径宽度及其不确定度，与当前安装纪元的四槽位经验指纹库比较。

亮反光脊的 FWHM 只是一项成像/散射诊断，不是狭缝宽度。算法允许反光金属到达饱和值，也允许以饱和覆盖率的凹口证明黑缝；只有整个测量走廊在长曝光中处处完全裁剪、黑区和第二边都不再留下任何动态范围时，该曝光档才只作为上限证据而不参与测宽。

机械序号与光学身份必须同时通过。程序不会因为光学结果更像另一个轮位就自动改写标签、重排映射或移动狭缝轮；这类结果以 `SLIT_LED_IDENTITY_POSITION_MISMATCH` 阻断任何入缝、导星和科学曝光，并提示检查安装、标签或 ordinal 映射。

## Commissioning 数据

schema 4 commissioning preset 必须包含一个自哈希的 `SlitWheelIdentityCalibration`。它与精调拓扑使用同一个 `InstallationEpochId`，并绑定：

- G3 稳定身份；
- X/Y binning；
- 实际交付图像宽高；
- 最大归一化残差和最小 runner-up 分离度；
- 测量模型 `UVEX-DARK-APERTURE-TWO-EDGE-HDR-V1`、短/长曝光时间和当前安装纪元的共享边缘 PSF；
- 轮位 1、2、3、4 各自的人工确认标签、标称物理宽度、暗孔径实测像素宽度、两边缘分辨方式、反光边到物理中心偏移、第二边振幅比、经验不确定度、UTC，以及短/长曝光各自的独立证据 SHA-256。

本机 UVEX4 的声明映射仍是 `1=300 µm、2=15 µm、3=25 µm、4=35 µm`，但程序不从这些微米数按比例推算像素宽度。PSF、散焦、衍射、照明轮廓、binning 和相机采样都会破坏简单比例。四个轮位必须分别取得不可变 LED 证据，证据哈希不得复用；两个指纹若没有达到配置的统计分离度，整个库不能 commissioning。

为避免第一次建库时就把人工错名固化进去，程序还做一项不依赖标签文字的全轮光学排序：在同一相机几何下，实测像素宽度必须与物理宽度 `15 < 25 < 35 < 300 µm` 保持严格同序。它不假定线性比例，只使用“更宽的实缝不能投影得更窄”这一物理关系。因此若轮位 2 和 3 实物装反、但 definition 仍照抄 `2=15、3=25`，commissioning 会明确报告 optical-order/installation mismatch，而不会生成一个自洽但错误的库。

建议每个轮位至少重复取得多组无运动九帧序列，以组间散布而不是单帧拟合误差建立 `WidthUncertaintyPixels`。更换相机姿态、ROI/binning、C11/G3 光学安装、狭缝轮或照明结构后必须换新的安装纪元并重测四槽位。

## 运行时判定

自动观测只在进入 `AcquireG3SlitField`（取得 G3 狭缝场）并且确实要生成 fresh 目标/狭缝
几何时自动亮灯检测；单独在“设备手控”中打开 LED 只改变灯的状态，不会自动启动分析。
自动序列开始前必须已经加载 schema-5 commissioning 与四槽身份库，Night Setup 的 C11
焦点所有者/锁定位置通过，PHD2 身份与不可变 Profile 证据通过，光路盖已打开，并且即时
安全/设备所有权门允许。随后程序在赤道仪无运动状态下分别按锁定短曝光和长曝光执行
`OFF×3 → ON×3 → OFF×3`，合计 18 张 G3 FITS；每个 LED 命令必须完成并回读，所有帧都
绑定即时 mount readback 和 SHA-256。正常结束、暂停、取消、异常或超时都会在 `finally`
中强制关灯并核对 OFF，关灯无法证明时流程保持阻断。

G3 长曝光解算阶梯本身不亮 LED。只有阶梯已经取得可用 WCS（或按稀疏场/目录目标策略
允许继续尝试狭缝几何）后，才进入上述 18 帧检测。邻场搜索、失败后的 fresh reacquire 或
重新开始 `AcquireG3SlitField` 会再次运行，因为旧帧不能证明移动后的当前狭缝/目标关系；
普通科学曝光和持续导星期间不会周期性闪灯。

运行时将本轮测量不确定度与每个参考指纹不确定度按平方和合并：

`sigmaCombined = sqrt(sigmaFresh² + sigmaReference²)`

每个候选的归一化残差为：

`z = abs(widthFresh - widthReference) / sigmaCombined`

只有以下条件全部成立才通过：

- fresh LED 几何门本身通过；
- calibration 自哈希、四槽位完整性、证据唯一性和 detector geometry 有效；
- 最佳候选在 `MaximumNormalizedResidual` 内；
- 最佳与第二候选的残差差达到 `MinimumRunnerUpSeparationSigma`；
- 最佳候选的轮位和标称微米宽度同时等于 UVEX 实报与锁定 Night Setup。

无匹配是 `SLIT_LED_IDENTITY_OUT_OF_FAMILY`，不唯一是 `SLIT_LED_IDENTITY_AMBIGUOUS`，相机/binning/图像尺寸变化是 `SLIT_LED_IDENTITY_DETECTOR_MISMATCH`。三者都不授权运动。

每轮会写 `slit-wheel-optical-identity` JSON，保存完整 18 帧路径/SHA、短/长曝光、反光边与暗孔径两套几何、过曝覆盖率/动态范围、机械声明、实测宽度、不确定度、四个候选残差、匹配结果、calibration ID/SHA 和最终 gate。N.I.N.A. 的“高级设置”只显示经过 preset SHA-256 验证的库摘要及最新 fresh 判定。

## 现有历史证据的边界

2026-08-18 的 G3 1×1、1920×1080 派生复算对当时声明的 15 µm 槽位曾报告约 `9.032 ± 0.590 px`、几何置信度约 `0.895`。该数值同样来自亮反光结构，不再是 schema 2 物理宽度候选；原九帧仍可作为几何/共享 PSF 的历史输入，但必须与相容的长曝光重新按暗孔径双边模型派生，且不能据此推算其他轮位。

## 2026-08-19 四槽位实机轮测：已废止的反光宽度解释
