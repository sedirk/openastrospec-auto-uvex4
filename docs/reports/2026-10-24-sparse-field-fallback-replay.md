## 以前讨论的路径：设计与实现不能混为一谈

1. **单邻场 WCS + 到位读数 + 新像素测量**已经生产接通，见
   [ADR-0030](../adr/0030-exploratory-neighbour-field-continuity.md)。HD 221662
   本轮就是正对照：两张短帧的 39.8874 px 所需包络小于 44 px，实际获得了
   `G3_POST_WCS_MEASURED_FINE_HANDOFF` 警告放行，不是还被历史 20 px 卡住。
2. **双镜差/配对 WCS**已采集、归档，并可在同 run 为新 QHY 提供 G3 搜索提示；
   不是 Active 全域模型。现有生产配置明确 Skip Active transfer，没有完整的
   跨 run 激活、适用性和退役消费链，见 [ADR-0004](../adr/0004-optional-versioned-wide-to-slit-field-transfer.md)
   和[快速双镜配对](../qhy-g3-fast-solve-pair.md)。不把单样本偷偷改成运动权限。
3. **多节点重叠拼图与低匹配时间聚类**仍是设计待办。现有相邻搜索网格不等于
   已经实现多节点图求解器，OBS-014 和[稀疏场设计](../design/faint-target-and-sparse-field-acquisition.md)
   明确如此。本轮离线配准/叠加实验也不是生产马赛克运动控制器。

## 本轮修复边界

修复现有设计的接线遗漏，不改变暗点源模式、原运动/次数/时间预算或天气规则：

- 在已发生 WCS 修正、目标超精调包络的同一张图上，bin2 正常完成但无解或
  不合理时，原时限内至多补一次原分辨率解算；不另拍一轮，异常/取消/身份或
  parity 不符不算普通解算重试。HD 220526 的上述失败帧仍无解，不能宣称此补试
  单独救回它。
- 已有 ADR-0040 的停止后当前位置交接不应在取得新图之前先被旧 9″ 接续
  路径强制送回原点。保留一次本地停止证明、原预算完整回程余量；新图、镜侧、
  所有者及绑定通过后才执行原保守扣账。自己的单帧采集不能用 loop/stop 破坏
  这份证明，也不能在外部会话变更后伪造新的证明。
- 对有原像素的普通候选，仅排除其 3 × 3 核中值同时不高于背景和局部环带的
  明确无支撑点。保留弱正峰、近邻歧义、原搜索半径和多瓣拒绝，不把窗外亮核
  自动改认成目录目标。历史 `00082` 用于复现误选，其他真实目标作为正对照。
- 新图交接仍使用原运动时钟，在每次取图/解算前计算当前位置的完整回程与
  清理预留。直接取场成功也必须核验新图绑定、完成原账本接续并消费停止证明，
  不允许旧证明流入下一次选星，也不因已回到原点附近就漏记相对上次端点的位移。

完整多节点拼图、跨 run Active transfer、真实天区端到端成功率仍须单独验收。
本报告不承诺稀疏/过曝/云遮帧必然可解，也不以“星已进框”代替身份和入缝实测。
