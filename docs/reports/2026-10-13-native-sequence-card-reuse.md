# 原生高级序列卡片复用与收尾组审计（0.4.0.289）

## 请求与结论

审计类似“序列开始自动启动安全监视器”和“每目标强制校准”的自定义选项，能复用
原生卡片则复用，不等价则暂不硬换；让收尾位置明确、附加指令可编辑。

核对本机 **N.I.N.A. 3.2.0.9001** 的实际 `NINA.Sequencer.dll` 类型和对应源码，
不是仅根据最新文档猜版本能力。官方高级序列本来就有 Start/Target/End 三个区域；
原生末尾不是 `finally`，取消或某些错误跳转可以绕过 End。

| 功能 | 审计结论 | 本轮处理 |
| --- | --- | --- |
| 连接安全监视器 | 原生 ConnectEquipment 支持 `Safety Monitor`，已连接不重连；不会保证 Safe 或锁定身份 | 完整模板直接使用原生卡；旧自定义卡移入兼容分类，不破坏旧文件 |
| 等待安全/等待时刻 | 原生卡可以使用 | 保持复用；新准备组使用 WaitUntilSafe，不重复写等待器 |
| 目标身份、坐标、复制/排序、三段布局 | 已使用原生目标模型、坐标控件及容器 | 保留，不再造一份目标编辑器 |
| 每目标强制校准 | 原生 StartGuiding 支持 ForceCalibration，但只开始导星；不负责光谱一次计数、预算与校准后重新取场入缝 | 保留目标选项，注明不能叠加原生开始导星；底层依然由 PHD2 执行校准 |
| 初始导星稳定/自动恢复 | 原生开始导星不能替代移锁账本、失星等待、重新选星、一次校准和有限恢复 | 保留协调参数，不改三帧实测、所有权和失败跳目标链 |
| 固定/自动曝光、合格帧和尝试上限 | 普通 Take Exposure 不负责 ATR 试拍选档、验收及已拍帧一次计数 | 保留共同 ATR/科学采集流程，不换成裸曝光卡 |
| 中天翻转 | 已使用 N.I.N.A. 原生翻转接口，但光谱需重新取场、入缝及剩余帧续拍 | 保留现有薄协调层；不再增加独立翻转路径 |
| Home/Park/关顶 | 原生动作有对应卡，但机械次序、无干涉台站确认、停止/到位读回和独立安全待机不可拆散 | 仍由同一整夜所有者执行；设置集中到可见收口卡 |
| 附加收尾 | 原生 End + SequentialContainer 可直接承担编辑与执行 | 新完整模板显式呈现 End 和可拖卡的附加组，仅补一个正常收口条件，不新增执行引擎 |

参考：[官方高级序列结构](https://nighttime-imaging.eu/docs/master/site/sequencer/advanced/advanced/)、
[官方原生指令说明](https://nighttime-imaging.eu/docs/master/site/sequencer/advanced/instructions/)。
本机安全监视器连接能力以已安装程序集及对应 `ConnectEquipment.cs` 为准。

## 实现边界

- 完整示例：原生准备组 → 光谱整夜目标 → 原生 End 中的收口选择与附加顺序组。
  模拟示例准备组的原生循环次数为 **0**，不依赖不会持久化的 Disabled 状态；
  建立真实计划时明确改为 **1** 并配置 REAL。
- 收口选择在夜间启动时读取并锁定；末尾卡不是第二个屋顶动作。即使目标错误退出，
  夜间 `finally`／独立待机仍执行保存的策略与安全链。保持开顶时不让附加卡抢设备。
- 附加组只在本夜正常关闭、已停且未结责任为空时运行一次；模拟结果不标为真实回读。
  取消、Unsafe、晨光/截止、安全待机和未结失败全部跳过附加动作。质量失败被正确跳过、
  后续目标正常结束且安全收口确认，不会无故禁止附加组。
- 原生额外卡片可自行拖入、删除和排序，例如主控 ATR 回温；不自动添加回温或断连，
  不默认停止安全监视器。不得拿主控卡片去控制 worker/PHD2 所属相机。
- 本轮执行证明不保存、不克隆；原生组在第一条动作前记一次尝试，局部重置不会重放
  已经尝试的附加动作。卡片自身原生错误/重试选项仍明确可见。
- 多张收口卡、没有保护条件的 End 设备动作、多夜归属不明确属于布局错误，给出
  放置办法，不选择任意策略。没有新增观测质量阻断。
- 单独复用的 TargetBlock 没有根 End，继续使用末尾收口卡。只克隆夜间容器时，
  外部选择保存到原有 keep-open 兼容字段；整份序列另存/重载不制造重复收口卡。
  .288 及更早的启动卡/末尾卡继续可读，没有批量重写用户观测文件。
- 夜间面板折叠旧版收口字段，Home 选项可从收口卡设置；晨光、截止仍直接显示。

设计变更见 [ADR-0036](../adr/0036-native-sequence-preparation-and-end-area.md)。
按明确的布局设计请求更新冻结基线及其散列；不变更 ADR-0001 或设备所有权。
