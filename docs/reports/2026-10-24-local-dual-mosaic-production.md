# 局部双镜与重叠拼图的生产退化闭环

日期：2026-10-24。设计依据为 [ADR-0043](../adr/0043-local-dual-optics-and-overlap-mosaic-recovery.md)。
本记录区分生产接线、历史原图实验和实天验收；发布检查与安装回执见文末。

本轮验证的 `actorScope` 是 **offline-history-replay**：只读既有观测、在忽略目录
生成新的派生图并运行隔离的图像解算器。没有连接物理相机、控制设备、开始观测，
也没有把日志重放或程序安装写成新的天空观测成功。

## 生产路径与实际边界

两种前端继续使用同一 G3 取场 runner。已有正式参考场且新图能独立注册时，
可先使用新图注册传递，省去等待同一帧再次完整解算失败；首次直接解算和其他
退化仍共享原有曝光、运动、次数、回程、清理及整夜截止，不另发一套预算。

- 局部双镜差：从已认证的同指向 QHY/G3 正式解算对拟合小范围预测。训练样本
  必须早于本次 QHY；最新的独立样本留出验证，不能将本帧或未来样本混进拟合。
  当前 QHY/G3 的实际曝光时段和光学漂移还须分别检查，赤道仪坐标稳定不代表
  像面没有极轴误差、跟踪漂移或旋转。
- 重叠取场：由实际尺寸、像元尺度和双端点不确定度收紧已有搜索步长及粗修正。
  未知方向使用短边约束；不能继续把固定 300″ 当成任意相机方向下都有重叠。
  更小的中间步仍花原有动作/累计量/时间，无法装入原回程预留时不出发。
- 注册图：同一运行、相机所有者/连接历元、焦位、镜侧和几何中，每条实际像面
  注册边使用 3 颗空间分散的拟合星与至少 2 颗未参加拟合的留出星。已知目标及
  光晕区域排除；等支持的矛盾图案、尺度/旋转异常、独立点不足或重叠不足不晋级。
  同组件的其他可注册路径还须闭合，不能用最先匹配的邻帧掩盖矛盾。
- 真正拼图：只有独立注册后的原图像素才能进入派生画布。记录父源散列、变换、
  贡献和覆盖，再调用现有 PL3 正式解算。绝不按赤道仪命令坐标拼接假星场。
  派生画布右/下可补最多一列/行背景像素以使用完整 bin2 块，不裁剪原图，
  不改变注册参考原点。正式拼图结果再反投到当前原图。
- 推断与实测：`RegisteredNeighbourWcs`、`RegisteredMosaicWcs` 和
  `LocalDualOpticsPrediction` 都不是“当前原图 native solver 成功”，不得进入
  新双镜训练样本，不能单凭预测点启动 PHD2 精调或 ATR。须继续取得独立新短帧
  目标/狭缝复核，之后仍走原 PHD2 和科学质量链。

这些替代路线的光学失败只是本目标可用方法不足；在原预算内继续其他方法，
耗尽且停止/账本结算确认后遵从保存的跳目标策略。Unsafe、取消、身份/所有权改变、
源文件完整性异常及未确认停止不变成普通光学失败。

## 局部双镜模型的冷启动与旧记录

生产局部模型至少需要 **3 个独立 schema-2 焦位绑定样本**：至少 2 个更早的
训练对，以及 1 个独立、较晚的留出验证对。还要具有实际天区跨度，而不是同一
指向重复拍 3 张。运行时检查安装纪元、镜侧、相机/光路/赤道仪身份、ROI/binning、
奇偶性、增益、Night Setup、commissioning 和两个光路的焦点状态；原文件、
正式解算、焦点证据及清单均可重新核对散列和语义。

旧 schema-1 单配对缺少 run-local C11/GS350 焦点来源。即使设备 ID 与 preset
看似相同，也不能自动补填焦位、把旧 Candidate 或 latest 索引提升为可用模型。
历史审计中曾出现同 preset 的 C11 焦位由 5000 改为 4800，正说明 preset 相同
不能代替当前光学状态。冷启动期间，直接 G3、重叠邻场/正式锚和拼图路线仍可用；
并非先要求操作员手写双镜常数才能观测。

本轮历史双镜回归可以从原审计日志明确重建焦位，用早期真实配对预测第四个场，
并保留后来真实 G3 正式解作独立比较；这种 fixture 的用途仅是离线算法验证。
它不会写入生产 schema-2 档案，也不证明当时的旧程序本来具有完整自动激活资格。
不能把跨日、不同焦位的历史成功配对混作今晚的全域固定光轴差。

显式因果回放使用 Oct23 第 1、2 对训练、第 3 对独立留出，预测第 4 对
HD 221662。中心误差为 **5.243952″ / 13.6695 px**，包含角点、时间和空间
适用性的保守不确定度为 **21.810879″ / 56.8549 px**，仍在原 100 px 识别
范围内。只读 audit 支持这些运行实际焦位为 4800；错误套用 Night Setup 的
5000 假定被拒绝。Oct14 不同配置的成功记录也不会被混进该局部模型。

历史记录没有两张同场、短间隔的 QHY 正式解，因而不能拿它们声称已验证
“广域光学码盘”的实天精度。双 QHY 漂移正例来自有限测量替身，历史过期/
不同指向数据作为拒绝反例；没有为通过回归而新增实机曝光。

## 实际原图拼图与 PL3 正反实验

原始目录与 FITS 保持不变。实验直接调用新的 C# `G3OverlapRegistration`、
`G3MosaicComposer` 和 `G3RegisteredWcs`；生成的新临时 FITS 再交给隔离复制的
PL3 executable/config/library。结果同时核对 native True/False、exit code 0、
未超时、输入和已安装解算器散列；没有只拿进程启动或返回文本存在当成功。

### Oct14 HD 219937：空间算法正控，不是实时生产准入证明

来源运行 `UVEX-20261014T112329Z-1862faa86ec84de`，当夜曾接受 2×300 秒。
本实验读取其证据 44、49、51 三张 2 秒 G3 帧，在目标周围 130 px 排除区之外
进行独立场星注册。构造的真实像素派生拼图得到：

| 项目 | 实际结果 |
| --- | --- |
| PL3 原生结果 | True；exit 0；未超时 |
| 提取 / 匹配星数 | 15 / 8 |
| PL3 耗时 | 1.250 秒 |
| WRMS | 3.781925 solver pixels；不是直接的原始像素或角秒 |
| 反投最后一张原 51 的目录点 | `(857.4357, 456.7283)` px |
| 未参加注册/解算的原 51 历史主体实测 | `(857.1297, 459.0807)` px |
| 二者距离 | 约 2.372 px |

最后一张 2 秒长帧的普通识别器仍返回 `TARGET_AMBIGUOUS`，两个候选相似，
uniqueness 约 1.07。回归保留这个拒绝，不为了使拼图实验看起来闭环成功而
放松身份或多瓣规则。上述结果验证了真实像素配准、拼图正式解及反投的一致性，
不是已经完成新短帧、PHD2 入缝和接受光谱。

更重要的是，这组图有约 **200 秒**的张间间隔。按本轮新增的实时窗口，
**它只能作为空间算法/PL3 正控，不能宣称会被生产实时拼图组合接受。**

### Oct23 HD 219937：时间窗口内可组合，但仍没有正式解

来源运行 `UVEX-20261023T123550Z-ed9c198f39b64e7`，证据 75、80、82、84、86。
均为真实 2 秒 G3 帧。排除亮主体周围 100 px 后，实际独立配准和图闭合通过；
86 不能直接可靠配 75，但能通过较近帧构成连通边，不能要求全部图只配第一张。

这组新 C# 真实像素拼图的 PL3 结果仍为 **False，10 detected / 0 matched，
8.453 秒，exit 0、未超时**。它在相邻中点 60 秒、连通跨度 120 秒的组合窗口内，
但时间准入不是天空解算成功，软件不能补造缺失的目录匹配。
PL3 失败的原生结果保留；不会因为五张图确实有同一主体就称目录身份已证实。

### Oct23 HD 220526：缺失覆盖不能补造

来源运行 `UVEX-20261023T124609Z-4f199a0a5f07404` 的 33→37 原图。
此前约 747″ 的场间改正使实际重叠不足，新注册必须拒绝；只有三点自拟合、
没有足够独立留出证据不能组成拼图。这个反例驱动本轮对取场步长/粗修正的
重叠约束，而不是把拒绝门关掉。源 33 以前的独立 PL3 正控成功，也不能使
没有验证边的 37 自动获得 WCS。

## 曝光时段、张间间隙和解算延迟

下表时间来自原 FITS 的 `DATE-OBS`，曝光时长字段实际为 `EXPOSURE=2.0`；
没有假设缺失的 `EXPTIME` 或 `DATE-END` 存在。每张中点按起点+1 秒计算。
文件名中的 UTC 是预留证据路径时刻，可能早于真正曝光，不能替代快门时刻。

| 来源 / 帧 | DATE-OBS（UTC） | 与前帧中点间隔 | 扣除曝光后的张间空隙 |
| --- | --- | ---: | ---: |
| Oct14 / 44 | 11:28:45.151 | — | — |
| Oct14 / 49 | 11:32:05.207 | 200.056 s | 198.056 s |
| Oct14 / 51 | 11:32:07.860 | 2.653 s | 0.653 s |
| Oct23 / 75 | 12:44:37.600 | — | — |
| Oct23 / 80 | 12:45:25.393 | 47.793 s | 45.793 s |
| Oct23 / 82 | 12:45:28.038 | 2.645 s | 0.645 s |
| Oct23 / 84 | 12:45:30.414 | 2.376 s | 0.376 s |
| Oct23 / 86 | 12:45:33.072 | 2.658 s | 0.658 s |

Oct14 这组从首帧开始到末帧曝光结束为 204.709 s；Oct23 为 57.472 s。
两次实际 PL3 又分别额外消耗 1.250 / 8.453 s。不能把这些延迟从原预算里抹掉，
也不能把 solver completed time 写成新的 image captured time。

生产默认实时限制为：当前帧最早可能曝光中点到使用时刻不超过 45 s；相邻
中点间隔上界不超过 60 s；连通图中点跨度上界不超过 120 s。可在本版内收紧，
不借此延长原目标/回程/整夜截止。NINA/PHD2 只有 native 请求与完成 bracket
时，保存较宽的中点区间；只有 FITS 曝光起点与该真实 bracket 相容才使用它
收紧区间，不把 save_image 完成当成精确快门时间。

独立图像位移或双 QHY 正式天空解可产生有来源的漂移上界，将曝光期间的
模糊和曝光后延迟加入预测不确定度。未知漂移不当成零，稳定赤道仪 readback
不等于图像稳定；没有漂移证据不能做时间外推。当前已注册原图的空间表示
也仍需新的独立短帧对，推断会在消费前重新检查时效及源散列。

双 QHY 路径对两张广域帧分别记录曝光区间半支撑和积分拖移误差，并将其
传播到差分漂移率；G3 的半曝光时长与 PC 中点时间区间半宽共同计入位置
误差。固定三个曝光中点、位置和实测漂移率，仅延长 G3 或 QHY 曝光的两个
反事实测试要求误差增长，且不能获得新的识别误差或时间额度。这样不会把
长曝光中心解算成功误读成“整个曝光期间均精确停在这个点”。

## 可重复回归与证据范围

- `G3OverlapRegistrationTests`、`G3OverlapGraphConsistencyTests` 覆盖独立
  holdout、等支持别名、反射/尺度/角度、排除目标、无重叠、取消、真实像素
  合成、重复父源和分配上限。
- `G3RegisteredWcsTests` 覆盖 NINA PL3 补角、其他 solver 角度及拼图偏移反投。
- `RecordedG3OverlapTests` 只读上述原帧，检查前后 SHA-256。显式提供实际
  PL3 回执时，还重新读取其派生 FITS，与当前生产 composer 输出逐像素比较，
  再消费 True/False、退出码、超时和反投；不是用另一份 Python 合成结果代替
  C# 生产算法。
- `RecordedQhyG3LocalModelTests` 区分过去样本因果预测、显式历史焦位 fixture
  与生产 schema-2 自动加载；跨日旧状态、未来/本帧自证不得产生新权限。
- 实验产物保存在本机忽略目录 `tmp/mosaic-0311-production/`、
  `tmp/mosaic-0311-pl3-success/` 和 `tmp/mosaic-0311-pl3-failed/`，不入 Git。
  详细复跑环境见测试类的 `UVEX_REPLAY_OBSERVATIONS`、
  `UVEX_MOSAIC_PL3_SUCCESS_REPORT`、`UVEX_MOSAIC_PL3_FAILED_REPORT`。

代码接入和离线实验并不保证稀疏/云遮/失焦目标必然可解，旧记录缺少的焦位、天空覆盖或短曝光
证据也不会在这次维护中追溯生成。新的完整生产路径仍须在另行授权的正式前端
观测中验收，安装请求本身不授权开始这一轮。
