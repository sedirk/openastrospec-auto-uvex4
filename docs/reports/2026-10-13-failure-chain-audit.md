# 失败跳目标全链路审计与修复（0.4.0.288）

## 范围与结论

沿失败生产者 → 阶段/恢复包装 → 协调器终态与持久化 → 独立停止确认及账本退役 →
原生目标结果 → 下一原生目标执行逐层检查。覆盖 G3 取场、WCS 居中、邻场搜索与回程、
独立狭缝修正、PHD2 入缝/回程/科学恢复、ATR 试拍与科学计数、取消及独立安全待机。
保留 .286 的 ATR 档位/选星/空场修复与 .287 云后恢复预算修复，不通过追加一批字符串
白名单解决本次问题，不修改冻结设计、安全阈值、运动限额或原始观测。

发现的同类问题不止“漏了可跳过代码”，还包括反向错误：把真正的设备/账本错误包装成
可跳过的恢复耗尽。两种错误必须一起处理。

| 层次 | 遗漏及影响 | 修复后的边界 |
| --- | --- | --- |
| 预算生产者 | 合法时间/次数/累计运动耗尽默认 Run，整夜误停 | G3 往返、狭缝分段、PHD2 规划/科学重建明确 TargetQuality；无效账本/非有限值/倒退时钟优先保留 Run |
| G3 回程与搜索 | 回程只保留文字；搜索结果一律覆盖原代码，可能误停或误跳 | 返回对象携带原 Gate；成功返回也不掩盖设备故障；预算拒绝不伪装未确认到位 |
| PHD2 恢复包装 | 账本读取/绑定拒绝被换成恢复耗尽；科学重定位拒绝一概质量化 | 生产规划器的明确预算代码映射为目标失败，其他原始失败贯穿传播；嵌套类型异常不降为普通重试耗尽 |
| PHD2 实测回程 | 原帧/会话异常都变成 POSITION_UNCONFIRMED | 有限窗口未到位或同会话 LostLock 为目标失败；换主/中断/陈旧或缺少实测位置另码保留 Run |
| 原生终态 | 从全部历史 gate 中取最后失败，可能拾取其他阶段旧状态 | 读取当前终止阶段，仍要求终态事件代码一致、协调器已 join |
| 夜间竞争 | 停止确认期间取消/Unsafe/截止已发生仍可能决定 skip | join 和停止确认后重查取消、Unsafe、EndNight、截止/晨光；真实目标无 owner boundary verifier 不能凭空当作已停 |

旧策略仍生效：SkipQualityFailure 才可跳过；EndNight 不跳。失败目标仍是失败，不改成
Completed。单目标失败不主动关顶；屋顶由保存的整夜策略和独立安全待机负责。
这不是“所有失败都继续”，也不是“回程未到位便直接再动”：原归档必须匹配本次运行与
设备身份，采集/导星/运动必须独立确认停止，才能放弃旧回程并为下一目标重新定位。
原预算与原始帧不被清零、重置或改写；未知异常仍保留可见故障。

## 不可弱化的安全链

- 天气 Unsafe、晨光、原截止、人工取消/结束不能进入下一目标。
- 设备断连、所有权/身份/绑定错误、主动运动未停、停止或持久化失败不能被预算类覆盖。
- 不授权超单步/半径/电子或机械限位的动作；拒绝动作不等于允许越限。
- 无效/超支/非有限账本或未来时间不是普通“预算刚好用完”。
- 新增 Run 区分码用于阻止拿未知会话、无实测来源或损坏账本继续运动/曝光；测试确认
  不会启动下一目标，恢复仍需既有停止和重新验证流程，不通过清空旧账本绕过。
- ATR 科学验收、已接受帧、试拍复用一次计数、天气监视器选择和独立待机租约不变。

## 回归方式

`FailureChainAuditTests`、`G3WorkflowTests`、`Phd2ScienceContinuationPolicyTests`、
`Phd2ConvergenceWorkflowTests` 和 `Phd2MeasuredReturnWindowTests` 使用实际生产
策略/流程生成拒绝结果，再驱动两个 N.I.N.A. 原生目标容器和协调器。断言下一目标
执行到 FinalizeObservation，journal 同时包含 SkippedQualityFailure 与 Completed。
并非仅断言分类器返回 true。设备接口为有限替身，不打开物理相机，不发运动命令。

矩阵覆盖时间/次数/累计预算及回程预留、实际回程工作流零派发、入缝/科学恢复、
停止失败、EndNight、未知代码、无效账本/NaN/未来时钟、身份/侧别/运动限制、
历史失败 gate 干扰，以及 Faulted 释放原生标记但持久化仍在 join 时收到取消、Unsafe、
EndNight、截止或晨光。未确认到位的结果保留 returnedToOrigin=false，不清空债务。

历史有产出记录继续只读对照生产判定与原文件 SHA-256；这不是完整 FITS 再处理，
也不宣称在真实云层、电子限位或设备掉线条件下已完成新一轮实天观测。
