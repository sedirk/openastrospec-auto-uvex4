# 原生序列跳过作用域修复（0.4.0.320）

## 问题与改动

已核对当前安装的 N.I.N.A. **3.2.0.9001** DLL（反编译只读核对）与源码提交
`2393eae581145ed5b8114bf07c48ca2580540fd5`。原生 `Sequence2VM` 的右下角
主按钮调用 `SkipCurrentItem → SkipCurrentRunningItems`；下拉项调用
`SkipToEndOfSequence → TargetArea.Interrupt`。原生指令的“发生错误时 →
跳过当前指令集”调用 `Parent.Interrupt`。没有在此版本中找到另一个独立名为
`SkipCurrentTargetCommand` 的高级序列命令，不能把错误策略下拉项说成手动按钮。
最初新增插件目标按钮的方案已按用户要求撤回，**未安装该中间产物**。

以这些入口及原生 `SequenceRootContainer`、`SequenceItem.Run/Skip`、
`SequenceContainer.Interrupt` 和 `SequentialStrategy` 的实际执行语义为准。
之前光谱目标的 `Interrupt()` 连带取消整夜；内部指令被跳过后的取消也被记录为
执行故障；原生 Target area 跳至 End 又被当作整夜取消，附加结束组因此被禁用。

本轮按 [ADR-0049](../adr/0049-native-sequence-skip-scopes.md) 修正：

| 操作 | 结果 |
| --- | --- |
| 原生目标／当前指令集 Interrupt/Skip | 取消并等待当前目标退出；独立核实采集、运动、交接账本；通过后真正执行下一目标。 |
| 原生“跳过当前指令” | 普通原生卡仍由 N.I.N.A. 处理；作用于内部光谱阶段时结束当前目标，不把跳过定位／导星当作已完成并直接曝光。 |
| 原生“跳到结束指令” | 跳过剩余目标，实际进入同一轮原生 End 区；按启动时保存的收口选择处理，再运行受保护的附加结束组。 |
| 原生停止／取消整个序列 | 不执行 End，不因取消而发机械命令；保留独立安全待机及原截止。 |

保持开顶时，不因进入 End 改成关顶，也不放行与安全待机争用设备的附加动作。
天气不安全、晨光、截止、停止未确认、清理失败或运动责任未结清仍优先。
没有本轮执行权／没有安全收口证明时，不能借“跳至结束”启动附加设备动作。
复用原生按钮、菜单和错误策略，参数仍锁定；没有新增按钮、页面、第二套执行器，
也没有改写正在使用的序列。

日志记录 `SkippedByOperator` 或 `SkippedNativeCondition`，不伪装成成功。
原片、已接受帧、尝试次数、累计曝光和原预算保留。新目标独立执行，旧目标不恢复。

原生 skip 枚举运行指令时持有可重入锁；同步取消可能在同一调用栈移除当前指令，
产生 Collection was modified。插件在内部阶段本地取消的返回边界异步让出，
使原生枚举先结束；不修改 N.I.N.A. 二进制、不用任意延时掩盖问题。

## 回归边界

直接调用当前安装 DLL 的 `Sequence2VM` 命令处理方法及原生错误策略分发，
运行真实 root / Start / Target / End 容器，只有设备 runner 被模拟。
离线测试绕过 UI VM 构造以避免后台检查和设备 mediator，不调用真实启动命令：

- 在取场、入缝和科学曝光阶段调用原生 skip，或目标 Interrupt／Skip。
- 等待故意延迟的清理结束，断言这之前下一目标和 End 都未执行。
- 清理通过后断言下一目标到达 Finalize；内部未完成阶段不冒充成功。
- 最后一个目标跳至 End、保持开顶、重复点击、局部条件、重复运行 End。
- 父取消、天气变化、停止失败，以及清理失败但随后空闲读回成功的负对照。
- 保留已有 1/2 帧、2 次尝试和 600 秒积分，跳目标不发起时钟／对焦恢复。
- 生产 XAML 离线渲染；断言不再提供重复的插件跳目标按钮，参数锁不变。

这些是离线软件回归，不是实天观测或真实机械收口验收。
