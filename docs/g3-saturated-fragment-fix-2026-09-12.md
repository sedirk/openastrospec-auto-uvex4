# 2026-09-12：G3 饱和碎片与零步搜索报错修复（0.4.0.179）

## 现场证据与原因

失败运行 `UVEX-20260912T131458Z-b1d65554d88c4ea` 已通过 USB/Night Setup。
WCS 多次确认织女星在画面内，但粗定位采用点在目录投影、饱和亮团和碎片之间跳变。
只读回放 `00042` / `00078` 原始 5 秒 FITS 复现：51,602 / 52,595 像素的巨大
饱和连通区域被 50,000 像素上限过滤，也随之失去对旁边小岛的排除作用；仅有
15 / 6 个像素的碎片反而被当作星心。过曝是触发条件，错误提升碎片位置是软件缺陷。

最终 `00088` 搜索摘要记录首步未发令：全局已用 10/12 次动作，而下一步和最坏
分段回程需要 3 次。预算保护没有失效；“已搜索但未找到目标”的文案不准确。

## 修复边界

- 巨大连通区域仍参加邻域排除，即使中心在识别窗外；不因参与排除而取得质心权限。
  本次没有提高 50,000 像素上限或扩大运动预算。
- 可见恒星的目录识别窗存在削顶像素时，长曝光只保留正式 WCS 身份，不再直接用
  饱和亮团/小岛修正目录位置。暗弱或明确不可见目标仍保持原目录路线，不强制星点可见。
- 共享生产 runner 在正式 WCS 成功后，使用已配置的短曝光、原生 PHD2 单帧、增益 0
  进行一次无移动位置复核。原 WCS 帧、解算证据、短帧哈希和前后赤道仪读回、历元、
  pier side、相机身份/尺寸/曝光必须匹配。未饱和且唯一的质心才可以补充位置。
  此短帧不参与对焦，不重复 PL3，不改保存的导星参数，不重置账本。
- 跨帧补充位置单独保存证据路径，绝不伪称“同一帧 WCS 质心”。WCS 运动求逆和到达
  预测均采用这个经读回绑定的偏移。旁星选择的长帧不再用饱和拓扑覆盖已复核位置；
  后续 PHD2 新帧残差和科学质量门仍须独立通过。
- 无法确认短帧星心时明确报告 `G3_CATALOG_SHORT_POSITION_UNCONFIRMED`；不能把
  这个不确定位置拿去继续盲搜。零次尝试的搜索停止独立报告
  `G3_SEARCH_NOT_STARTED_RETURNED`，保留首步前置失败原因与全局已用/剩余动作。
