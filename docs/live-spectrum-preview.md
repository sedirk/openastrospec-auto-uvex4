# 实时光谱预览复用后期提取（0.4.0.210）

本页对应自动观测中的 `实时图像 → 光谱相机 · 光谱`。本次不修改 M2/光栅闭环所用的
`SpectrumExtractor`、曝光选档、科学帧质量门或原始 FITS；手动光谱闭环检查也仍使用原来的
定量提取路径。实时预览不是最终归算结果。

## 原因与处理

旧自动预览按 ROI 的空间方向每隔若干行采样并平均（最多约 240 行），没有沿谱带提取，
也没有扣除天空。传入的 trace center/half-width 只影响显示范围。大量不属于光谱的背景、
热像素、宇宙线会混入曲线；画曲线时又跳过部分色散采样并按百分位裁峰，可能漏掉真实窄线。

新流程：

1. 立即显示当前帧谱带孔径之和减两侧天空中位数，保留负值；饱和列留缺口。
2. 后台把 ROI 的独立 `ushort` 副本交给 image-only Python 子进程。纵向色散先转置，
   不反转波长顺序、不改写输入。没有相机、串口、赤道仪、曝光或文件路径访问协议。
3. 直接调用后期 `uvex_reduce.preprocess._clean_cosmic_rays` 和
   `uvex_reduce.extraction.extract_spectrum`：二维 L.A.Cosmic 清理候选异常像素，
   ASPIRED 谱迹与 tophat 孔径提取，失败时使用现有稳健谱迹/孔径回退与验证。
   不是把 Python 算法重写到 C#，也不要求后期 GUI 正在运行。
4. 未 commissioning 的相机 Gain 设置不能冒充 e-/ADU。预览用当前空间条带的
   列背景 MAD 估计噪声方差，通过 `invar` 传给 L.A.Cosmic；后期默认调用不受改变。
   异常像素超过条带 2% 则拒绝清理，显示基础快览及原因。
5. 青线为实际返回的后期提取，灰线为**同一谱迹**的未清理背景扣除孔径对照，使用同一
   纵轴。灰线超出青线纵轴范围时在边界裁显，不表示坏点值变小；原始数值未改。
   曲线不做一维平滑，绘制每个色散采样。无效/饱和/越界列断线，不插值冒充测量。

预览明确选用 `optimal=False`，没有修改离线归算的默认提取策略。补测发现：在含曲线谱迹、
窄发射线和吸收线的合成图中，现有 Gaussian/Horne86 路径会改变相对谱形（注入的约 2.5 倍
发射峰被提为约 1.83 倍）。缺少完整噪声/空间轮廓标定的实时预览不采用这条路径，
不能靠调松谱线保留测试来让它通过。采用 ASPIRED tophat 后，清理前后的窄线一致性、
发射峰与吸收谷对比度回归都通过。图例显示实际 backend，说明区保留回退原因。
没有可靠 trace/足够天空时明确失败，不退回全图均值假装得到光谱。

原始二维图、FITS、采集计数、科学接收与曝光预算完全独立。当前曲线没有暗场/平场、
波长或响应标定；横轴为原始色散像素，纵轴为孔径 ADU，非物理通量。误差数组来自
预览估计，不能用于正式科学不确定度声明。没有在预览里混叠不同目标或曝光的帧。

## 后台与部署

- 最多一个 worker，不排队；忙时保留新帧基础快览，并明确说明。
- 45 秒总时限覆盖输入/输出及退出；超时只终止本次创建的 image-only 子进程。
  Python 崩溃、未安装或协议错误不影响曝光和安全门。
- 新帧/新轮会替换预览身份；旧 worker 只可替换同一个原预览对象，不能覆盖新图。
  更新保留原帧显示时间，不能把处理完成时间伪装成拍摄时间。
- 插件包包含从 `reduction/src/uvex_reduce/*.py` 原样复制的后期模块及入口脚本，
  安装器检查关键文件并比较复制后的 SHA-256。未修改已安装依赖。
- 默认读取本机后期 GUI 启动器的 `launcher.settings.json`，使用其中 ProjectRoot
  对应的 `reduction/.venv/Scripts/python.exe`。不扫描 PATH，不自动安装或升级库。
  其他机器可显式设置 `%LocalAppData%/UVEX-ADV/reduction-preview-runtime.json`：

```json
{ "PythonPath": "C:\\absolute\\path\\to\\pinned-venv\\Scripts\\python.exe" }
```

依赖继续使用 `reduction/requirements-lock.txt`。配置缺失时界面说明原因，基础快览仍可用。
未获得安装/重启授权时，代码及离线检查不能替代实际 N.I.N.A. 三面板验收。

## 回放与限制

`reduction/scripts/replay_live_preview.py --manifest <保存的 manifest.json> --output <独立输出目录>`
对最后三张至少 60 秒 ATR 帧进行只读回放，输出旧均值/未清理孔径/新提取比较图，
后期协议结果及逐文件处理前后 SHA-256。当前脚本假设记录来自全幅水平色散；非全幅
ROI 必须先按本轮配置切片，不能把全图回放冒充该配置的精确回放。

2026-09-20 保存帧回放：2026-09-16 的三张 600 秒目录目标帧，采用原记录中心
690/692/693 px、半宽 24 px。修正局部噪声模型后三帧候选清理计数为
3198 / 3016 / 3052，最终约 3.0–4.3 秒/帧（包括派生绘图；不是严格性能基准）。
最终三帧由稳健谱迹回退后进入 `aspired-tophat`；此前的 `aspired-horne86` 回放仅为比较，
不再作为最终交付算法。没有饱和缺测列，输入文件校验不变。
这些数值是异常候选，不是已确证宇宙线数；也不代表所有谱线科学通量都已独立验证。
初次未传实测噪声方差的回放过度标记约 6.9 万像素，保留其输出作为反例，不作为发布依据。

合成回归覆盖注入尖刺、窄发射线、吸收线、空图、饱和缺口、输入不变及真实 Python 管道。
实际天空的新采集与安装后原生界面待单独验收；不为预览发起设备曝光。
