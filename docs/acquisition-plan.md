# 采集计划（曝光预算）

自 0.4.0.172 起，常用曝光计划在 **自动观测 → 观测计划 → 采集计划（曝光预算）**。
“运行概览”也提供同名直达按钮。原“观测计划”拆为“目标与导入”和“采集计划”两个
子页，不把日常曝光设置藏在工程参数中，也不把校准库的暗场/偏置采集计划混作科学计划。

0.4.0.173 修正 .172 在较矮窗口中下半页被裁切的问题：两个子页的内容区分别支持
鼠标滚轮、右侧滚动条和触摸垂直滚动，空间足够时隐藏滚动条；顶部运行控制和页签固定。
“保存采集计划”位于曝光预算内容底部，窗口较小时向下滚动即可到达。

## 设置含义

| 设置 | 实际用途 |
| --- | --- |
| 合格科学帧数 | 本轮光谱接受张数目标。失败或仅保留的科学帧不凑数，试拍帧另计。 |
| 最大正式尝试次数 | 正式科学曝光的尝试上限，包含失败帧；必须不小于合格张数，不含自动选档试拍。 |
| 自动曝光档位 | 用逗号分隔的正秒数，如 `0.1,3,10,30,120,600`。运行按实际谱迹信号和削顶情况选档，不按整幅图的最亮像素选档。 |
| 起始试拍曝光 | 必须属于上述档位。是自动选档的起点，不是每张科学曝光的固定值。 |
| 并行观测与初始地平线规划时长 | 分钟。用于初始地平线预测和同步测光任务长度，不是总积分目标或切断已开始曝光的硬截止时间。 |

预算摘要分别显示“合格科学累计曝光范围”和“正式尝试曝光上界”，由当前档位、张数
及最大尝试次数计算。不把定位、试拍、下载、保存、导星或恢复时间算作科学积分。
例如合格目标 12 张、最终选中 300 秒，则合格积分为 60 分钟；选中 30 秒则是 6 分钟。
没有先选出曝光档位时不能给出一个确定总时长。规划窗口不足以覆盖最长档尝试及开销时
给出提示，不能将提示误解为已经修改计划或延长运动预算。

## 保存与锁定

1. 编辑时只是草稿，不修改当前生效设置。输入错误显示具体字段原因，不能静默保留旧
   数字同时假装新数字已保存；中文逗号可识别，数字的小数点使用 `.`。
2. 点击“保存采集计划”校验并写入当前 N.I.N.A. Profile，重启后保留。保存失败恢复
   之前的内存计划并显示错误。点击“还原当前计划”放弃草稿。
3. 未保存草稿时，自动观测面板的启动/新开一轮按钮不可执行，须先保存或还原；查看
   计划和后台只读查询不受影响。
4. 真实或模拟运行中，包括暂停/接管状态，计划编辑和保存锁定。结束/取消后才可设置
   下一轮；不热修改正在运行的配置哈希、科学计数、运动账本或未结回程。
5. 切换 Profile 重新读取该 Profile 的计划。此页不保存设备身份、温度、增益、光学
   设置、安全策略，也不改变屋顶或相机所有权。

面板保存仍写原来的 `AtrScienceFrameCount`、`AtrScienceMaximumAttempts`、
`AtrExposureLadderSecondsCsv`、`AtrProbeExposureSeconds`、`ObservationDurationMinutes`。
Dockable 与 Advanced Sequencer 仍由原配置快照/计划工厂进入同一生产 runner。
没有引入第二套采集循环，也没有增加后台任意参数写入接口。

后台新增 `show-acquisition-plan`，只派发运行概览直达按钮的同一个 `ICommand`，不需要
真实设备控制授权，不保存设置、不启动采集。日常保存仍使用页面上的显式按钮。
