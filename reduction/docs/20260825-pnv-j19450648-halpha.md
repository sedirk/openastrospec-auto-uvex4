**观测夜：** 2026-08-25（Asia/Shanghai）  
**目标坐标（J2000）：** RA `19:45:06.48` / `296.277000°`，Dec `+18:22:42.2` / `+18.378389°`  
**数据：** QHYminiCam8M Sloan/Hα 成像；ATR585M + UVEX4 光谱  
**系统 commissioning：** [QHYminiCam8M 测光与窄带联测记录](../../docs/qhy-photometry-commissioning-2026-08-25.md)  
**结果等级：** 相对测量、探索性；不是绝对分光光度或标准系统测光

## 结论

1. **目标身份已由 WCS 验证。** QHY r′ 帧经 PlateSolve3 解算并与 Gaia 做稳健映射后，目标预测位置与实际星点相差 `0.566 px`。画面中最亮的 `G≈5.83` 场星不是 PNV；不得用“最亮星即目标”的假设。
2. **QHY Hα 成像没有显著检出增强。** 28 颗比较星建立 `H-r` 对 `g-r`、`r-i` 的颜色关系后，PNV 的残差为 `+0.1085 mag`，场星稳健散布为 `0.1194 mag`，只有约 `0.9σ`，而且符号表示轻微 Hα 不足。一个曾出现的约 `+32%` Hα 表观增强来自比较星颜色不匹配，状态为 **REJECTED**。
3. **UVEX 光谱明确含宽 Hα P-Cygni 结构。** 在 12 张 600 s 原始谱中，7 张通过迹线/连续谱质量检查。七帧时间序列的净发射等效宽度中位数为 `5.508 Å`，稳健散布 `0.224 Å`；常用带符号写法约为 `EW(Hα)=-5.5 Å`。蓝吸收谷相对发射峰的探索性速度约 `-1,686 km/s`，但绝对波长零点没有本夜新鲜参考，不能把它报告为高精度径向速度。
4. **两套结果相容。** `EW≈5.5 Å` 在名义 70 Å Hα 和约 1330 Å r′ 带宽的简化模型中只产生约 `7.4%`、`-0.078 mag` 的 Hα 相对增强，小于本夜成像颜色模型的 `0.119 mag` 场星散布；所以“光谱检出、窄带成像未显著检出”并不矛盾。
5. **三根看似 Hα/Hβ/Hγ 的极窄尖峰是坏像素。** 它们分别位于原始色散像素约 `1252/3101/3663`，一度可以碰巧拟合巴耳末波长解，但二维图上各自只占一个空间像素且不沿约 34 px 宽的目标谱迹，状态为 **REJECTED**。不得再用这些尖峰作波长锚点、线强或目标分类证据。

## 4. Hα 窄带差分成像

### 4.1 正确的测量模型

每个滤镜先仿射配准到 r′ 参考帧，再用固定圆孔径和局部天空环计算曝光归一化 flux。场星颜色定义为：

```text
g-r = -2.5 log10(F_g/F_r)
r-i = -2.5 log10(F_r/F_i)
H-r = -2.5 log10(F_H/F_r)
```

28 颗未饱和比较星用于稳健拟合：

```text
(H-r)_pred = 4.260733 - 0.582552(g-r) - 2.117745(r-i)
Δ(H-r) = (H-r)_target - (H-r)_pred
```

这是本视场、本仪器设置下的**仪器色关系**，不是可移植的标准变换系数。

### 4.2 已拒绝的“+32% Hα 增强”

早期方法把目标 `F_H/F_r` 与未限制颜色的场星中位数直接比较，得到约 `1.29–1.39` 的增强因子。Hα/r′ 比值对恒星颜色非常敏感；当前 PNV 的仪器颜色约 `g-r=0.875`、`r-i=0.541`，任意 ensemble 的颜色分布与目标不同。颜色项加入后增强完全消失，因此：

> **REJECTED：** “本夜 QHY 窄带成像检测到约 32% Hα 增强”。

该数值不得进入论文、报告、软件默认样例或自动质量门。

### 4.3 颜色校正结果

| 量 | 数值 |
|---|---:|
| 目标仪器 `g-r` | `0.87497 mag` |
| 目标仪器 `r-i` | `0.54093 mag` |
| 目标实测 `H-r` | `2.71399 mag` |
| 场星关系预测 `H-r` | `2.60546 mag` |
| `Δ(H-r)` | `+0.10853 mag` |
| 等价 Hα flux factor | `0.90487` |
| 比较星 / 拟合内点 | `28 / 28` |
| 场星稳健散布 | `0.11942 mag` |
| 目标 Hα 七帧稳健重复散布 | `2.14%` |

`+0.1085 mag` 约为 `0.9σ`，不能声称检出；符号还表示相对连续谱预测的 Hα flux 略低。将矩形带宽公式机械套到中心值会得到约 `-7 Å` 的“伪吸收 pEW”，同样没有统计意义，不应作为科学结果。

如果把当前测量中心和场星散布都视为高斯近似，单侧 `3σ` 的发射方向边界为：

```text
Δ_lower = +0.1085 - 3×0.1194 ≈ -0.2497 mag
```

对应名义 70 Å Hα / 1330 Å r′ 矩形带宽下约 `+20 Å` 的 emission pEW 上限。这个上限是 **PROVISIONAL**：它受未实测滤镜曲线、颜色模型、非同时曝光、无正式 flat 和 HDR 线性未 commissioning 等系统误差支配。

### 4.4 注册和时间限制

g′、i′ 与七张 Hα 到 r′ 的仿射配准中位残差约 `0.17–0.25 px`，各 Hα 帧有 `43–117` 个内点，几何注册不是当前主要误差源。更大的限制是：g′/i′、r′、Hα 分别在约 20:46、21:02、21:26–21:41 拍摄，没有以 `r-H-r` 紧密夹逼；透明度变化和目标本身变化都可能进入颜色残差。因此本结果只适合作为 commissioning 和灵敏度评估。

## 5. UVEX Hα P-Cygni 光谱

### 5.1 提取

12 帧中位图上自动跟踪二阶谱迹，迹线中心约 `y=1686`。每列使用约 `±22 px` 源孔径，两侧独立天空窗扣除。原始帧每张全幅最大值可到 `65520 ADU`，但每张只有约 35–57 个固定热/坏像素；真实宽 Hα 迹线没有削顶。

一维谱先用 7 像素中值滤波去除单像素固定缺陷。真实 P-Cygni 结构横跨约 130 个色散像素，因此这个操作不会像对窄线那样抹掉主要结构。局部连续谱使用线两侧窗口的稳健二次拟合。

本夜没有新鲜弧灯或可靠绝对波长锚。局部色散 `0.946597867 Å/pixel` 来自[2026-05-04 Albireo Hγ/Hβ/Hα 解](20260504-albireo-processing.md)，只用于相对宽度、峰—谷分离和等效宽度积分；绝对波长零点和高精度径向速度状态为 `NEEDS_REFERENCE`。

### 5.2 被拒绝的伪巴耳末解

未清除固定缺陷时，一维谱在原始 x≈`1252`、`3101`、`3663` 有三根约 `1.88 px FWHM` 的尖峰。三点可以偶然拟合 Hα/Hβ/Hγ，得到看似漂亮的波长残差和约 `1.94 Å` 的“Hα EW”。二维检查证明：

- 三根尖峰各自只来自单个空间像素；
- 它们的 y 位置彼此不同；
- 它们不沿目标约 34 px 宽的空间谱迹；
- 相同 x 缺陷在多帧固定出现，符合探测器坏/热像素。

因此 `tmp/pnv_halpha_measurement.json` 及 `tmp/measure_pnv_balmer_spectrum.py` 的三线解整体为 **REJECTED**。形式上的三点低 RMS 不是真实波长标定证据。

生产管线由此必须要求谱线候选通过二维空间形态：至少沿谱迹覆盖与点源 LSF 相容的空间宽度；单像素列峰先进入坏像素/宇宙线诊断，绝不自动升级为线或波长锚。

## 6. 成像与光谱为何不矛盾

在最简单的矩形带宽近似中，纯发射等效宽度 `EW` 对 Hα/r′ flux factor 的影响为：

```text
factor ≈ (1 + EW/W_H) / (1 + EW/W_r)
```

取 `EW=5.5 Å`、`W_H=70 Å`、`W_r=1330 Å`，得到 `factor≈1.074`、`Δ(H-r)≈-0.078 mag`。本夜颜色模型的场星散布为 `0.119 mag`，所以 QHY 未检出完全合理。

而且本目标不是窄的单纯发射线：吸收谷离发射峰约 `36–39 Å`，接近名义 7 nm 滤镜的 `±35 Å` 半宽。真实滤镜边缘、中心波长温漂/入射角、Hα 发射和蓝吸收的不同覆盖都会改变窄带净信号。滤镜还可能混入 `[N II]`。因此不能直接把 7 nm 图像 counts 当作光谱 Hα 线流量。

## 7. 当前能发布与不能发布的量

### 可以保留为探索性结果

- 目标的 WCS 身份和 QHY 像素位置；
- `Δ(H-r)=+0.109±0.119 mag` 的本夜仪器指数，明确标注未检出；
- 本配置下一侧约 `20 Å` 的 Hα emission pEW 3σ 上限，明确标注矩形带宽和系统限制；
- UVEX 的宽 Hα P-Cygni 形态；
- 七帧净发射 EW 中位 `5.51 Å`、内部散布 `0.22 Å`，并附 `1–2 Å` 系统量级；
- 约 `−1700 km/s` 的探索性吸收速度，明确缺新鲜绝对波长参考。

### 目前不能声称

- QHY 已显著检出 Hα 增强；
- 约 `+32%` 的 Hα excess；
- QHY Hα 的绝对线流量或标准化 pseudo-EW；
- 精确 Hα/Hβ、Balmer decrement、消光或绝对响应；
- 三根单像素尖峰构成 Hα/Hβ/Hγ；
- 高精度绝对径向速度；
- 单凭本机单夜数据完成正式 nova 分类。
