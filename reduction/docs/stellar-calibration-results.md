# 本机标准星波长定标验证

验证日期：2026-08-15。数据来自 `<local-spec-root>`，模板来自随 ISIS 6.1.1 安装的 `isis_data3`。

## 使用的本地数据库

- 宽波段 Pickles 谱型模板：`p_b8v.dat`、`p_a0v.dat`、`p_f5iv.dat` 等，范围约 1150–10620 Å；
- 同名高分辨率模板：`UVEX_regulus.fits`、`UVEX_castor.fits`、`UVEX_procyon.fits`、`UVEX_arcturus.fits`；
- UVES/ELODIE 模板也存在，但当前自动算法优先使用覆盖完整探测器的 Pickles 模板，同名 UVEX 模板用于窄 Hα 设置的附加验证。

此外，已把 `26.2.18 Regulus` 的解实际套用到同夜 `Pollux-4..6`。目标成功输出 3854–7473 Å 的递增波长轴；谱图中的 Na D、Hα 和红端大气吸收结构落在合理位置。统一产物位于 `output/Pollux/2026-02-18/`。这证明“标准星建解 → 同配置科学目标复用”的文件链路可用，但不代表不同光栅设置之间可以通用。

“方向修正=是”表示输入配置先执行的水平翻转与实拍恒星线顺序相反。管线依据 Hα→Hβ→Hγ→高阶 Balmer 的唯一间距模式自动撤销该方向，最终 FITS/CSV/Spectrum1D 均为严格递增波长轴。

## 精度解释

表中的 RMS 是已识别恒星线相对于拟合多项式的内部残差，不是独立绝对精度测量。恒星径向速度、宽线/快速自转、Hε 与 Ca H 混合、目标在狭缝中的位置以及机械漂移都可能引入系统零点。两线线性解没有剩余自由度，因此不报告虚假的 0 Å RMS。

若需要更高绝对精度，仍建议拍摄相同光栅、狭缝、ROI、binning 下的弧灯，或利用已定标标准星得到初解后再以夜天/地球大气窄线修正零点。
