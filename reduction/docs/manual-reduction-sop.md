# OpenAstroSpec Spectral Studio — UVEX4 长缝光谱人工处理 SOP（初版）

**适用设备：** DIY/业余 UVEX4i 单长缝 Czerny-Turner 摄谱仪  
**当前设备预设：** C11 + CCDT67 + UVEX4i 电动版 + ATR585M，300 lines/mm，15/25/35 µm 可切换狭缝；2026-05-16 实测有效焦距约 2150 mm（f/7.7、0.769 倍）  
**文档修订：** 2026-08-16；加入 M1/M2、最佳像散 Y 与空间 FWHM-波长质量门  
**目标：** 在素材不完整时仍能可审计地降级处理，同时不把低等级结果伪装成
专业完整标定。

---

## 1. 核心原则

1. **原始数据不可改写。** SDK 修复、翻转、掩膜和配准只在内存或派生文件执行。
2. **每一步都有即时可视化。** 二维阶段看 FITS/迹线/天空，后续阶段看 1D、残差、
   响应和归一化结果。
3. **首选路径与降级路径分开标记。** 缺 arc 不等于有 arc；相对响应不等于绝对流量。
4. **质量门失败可以停止或降级，但不能静默通过。** 原因进入 FITS Header、JSON、
   工程文件和最终报告。
5. **设备预设是初值，不是真值。** 狭缝、光栅、相机方向、ROI、binning、减焦镜
   间距和对焦任一改变，都必须生成新的夜次配置快照。
6. **工程可恢复。** 用 `.astroproj` 保存目录、设备预设、流程预设、当前阶段、
   选框、人工批准状态、最近输出以及未来的标定点/算法参数。
7. **光学状态属于标定条件。** M1/M2 镜架角度、M2 电机焦点、目标在狭缝上的 Y、
   光栅托架状态和 CCDT67 配置改变后，旧的响应、LSF 和最佳 Y 不得静默复用。

## 2. 七阶段工作区

| 页 | 阶段 | 中央即时可视化 | 核心产物 |
|---:|---|---|---|
| 1 | 媒体 | 原始首帧 2D FITS | 分类清单、坏帧/冲突标记 |
| 2 | 主校准 | 标准星/flat 2D FITS | bias/dark/flat 决策与 master |
| 3 | 几何/提取 | trace overlay、天空窗、1D 初提取 | 对齐栈、trace、sky、flux |
| 4 | 波长标定 | 匹配线与残差、波长 1D | 显式 wavelength、线对、RMS |
| 5 | 响应/归一化 | 响应曲线和归一化 1D | relative/absolute 标志、continuum |
| 6 | 科学分析 | 谱线拟合、参考对照、指标 | line measurements、身份/QC |
| 7 | 交付 | 最终 1D | FITS/CSV/PNG/JSON/PDF |

不要把第 2 页“主校准”与第 4 页“波长标定”混为一谈。前者主要处理探测器与
照明校准，后者建立像素到波长的物理映射。第 3 页“几何”包括方向、倾斜、弯曲、
迹线和天空窗口；第 5 页“响应”建立波长相关灵敏度并决定能否称为绝对流量。

## 3. 专业路径、降级路径与禁止项

| 阶段 | A 级首选 | 可接受降级 | 无资料时 | 禁止 |
|---|---|---|---|---|
| 主校准 | 配套 bias/dark/flat | 跨夜兼容 dark、候选 flat 经质量门 | mask + empirical variance | 强行套不匹配 dark/flat |
| 几何 | flat/arc 建立 2D rectification | 科学帧稳健 trace，沿曲线提取 | 人工固定 aperture | 声称完成未做的畸变校正 |
| 波长 | 同配置 arc + atlas | 已知线对、标准星模板、同配置解转移 | 像素轴 `NEEDS_REFERENCE` | 伪造波长或把三点内残差当绝对精度 |
| 响应 | 分光光度标准 + 消光 | 恒星模板临时相对响应 | counts + 稳健连续谱归一化 | 把相对响应标为绝对流量 |
| 天空 | 两侧长缝 2D/B-spline | 逐列局部稳健估计 | 报告天空未充分扣除 | 把附近天空当乘性 flat |
| 二级光谱 | 截止滤镜或热/冷标准实测 | 保留数据并标记经验警戒 | 状态 `not_tested` | 在未知起点处武断裁切 |

## 4. 工程建立与状态持久化

### 4.1 新建工程

1. 双击桌面 `OpenAstroSpec 光谱处理 - UVEX4`。
2. 在“媒体”页选择原始数据根目录和输出目录。
3. 选择设备预设；确认主镜、减焦镜、光栅、相机、binning 和狭缝。
4. 填入当晚狭缝和初始色散度；历史值只用于搜索窗口。
5. 点击“保存工程”，使用扩展名 `.astroproj`。

### 4.2 `.astroproj` 必须保存的状态

- 数据与输出目录；
- 当前七阶段页面；
- 完整流程预设与是否试算 flat；
- 设备预设完整快照；
- 已人工批准的阶段；
- 最近一次输出；
- 标准星/目标选择；
- 二级光谱策略；
- 未来人工 pixel/Å 标定点和算法参数；
- M1/M2 调整版本、M2 焦点步数、光栅步数、目标 trace Y；
- 每块光栅的 `optimalTraceY`、空间 FWHM-波长基线和最近一次灯谱质量门结果。

关闭已有工程时自动再次保存。跨月恢复工程后仍应检查外部文件是否被移动。

## 5. 设备预设 SOP

当前内置三套固定光路预设，仅狭缝不同：15、25、35 µm。默认初始色散约
0.94 Å/pixel，来自 3C 273 / NGC 6543 正式产品的实测色散，只是搜索初值。原始
FITS 没有 `GRATING` 关键字；300 lines/mm 的判断由 3840 px 全幅约 3524–3624 Å
覆盖、约 0.944 Å/pixel 实测色散与 UVEX 官方光栅表共同支持，不应再由旧预设反推。

### 何时必须另存新预设

- 更换狭缝、光栅或相机；
- 相机拆装后色散方向改变；
- 更换 ROI/binning；
- CCDT67 间距显著改变；
- UVEX M1/M2 镜架角度、M2 电机焦点或光栅中心位置改变；
- 光栅托架倾角、柱面镜或狭缝到 M1 的轴向距离改变；
- 安装/拆除长波截止滤镜或校准附件。

预设名称建议：

`C11_CCDT67_UVEX300_ATR585M_35um_1x1_leftBlue_202605`

### 5.1 光学状态基线

每块光栅至少建立一次窄线灯/点源二维基线，并在拆装或调整后重建：

1. 保存三处以上波长的空间 FWHM、谱线偏斜度、左右翼和饱和比例；
2. 扫描狭缝高度，保存像散最小的 `optimalTraceY` 及实测可接受范围；
3. 保存 M2 电机焦点步数；该数值只代表纵向焦点，不代表 M2 镜架角度正确；
4. M1/M2 镜架每次机械调整生成新 `opticalAlignmentId`，不要只覆盖旧值；
5. LED 连续谱可用于 flat，但不能代替氖/汞等窄线源完成像差与线型检查。

官方判据摘要：M1 角度误差优先产生彗差和单侧不对称；谱迹空间宽度随波长
变化应检查 M2 角度；左右子孔径氖线分离则需要用 M2 纵向电机重新合焦。UVEX4i
还要求每块光栅测定像散最小的最佳 Y，并把目标放在该高度。

- https://buil.astrosurf.com/UVEX_project_us/
- https://spectro-uvex.tech/?p=9169
- https://spectro-uvex.tech/?p=11156

## 6. 第 1 页：媒体与原始数据检查

### 操作

1. 扫描 FITS；分类优先级为目录/明确文件名 > `IMAGETYP` > `OBJECT`。
2. 在媒体池按夜次、目标和角色分组。
3. 点击每组，检查中央原始 2D FITS。
4. 记录 Header 冲突、异常 BITPIX、尺寸、截断、饱和和相机型号。
5. 检查二维谱线连续性与读出完整性。任何循环移位只允许来自已验收的逐文件清单；
   禁止按多数状态或“首帧必然正常”作自动改图。当前清单见
   `toupsky-results-audit.md`。

### 人工质量门

- [ ] 文件名/目录与目标角色合理；
- [ ] 相机、gain、binning、ROI 组内一致；
- [ ] 曝光时间和温度可解释；
- [ ] 色散方向按该夜次确认；
- [ ] 狭缝、光栅、M2 和重新获取事件有记录；
- [ ] 异常帧被隔离而非悄悄纳入。

通过后点击“确认素材并进入主校准”。

## 7. 第 2 页：主校准

### 7.1 Bias

- 首选：同 gain/binning/ROI 的多帧 bias/offset master。
- 数量太少时报告噪声和局限。
- 不要用 Header 不匹配的 master 仅因为文件名叫 `offset.fit`。

### 7.2 Dark

- 冷冻相机允许跨夜复用；日期不是拒绝理由。
- 必须匹配相机、gain、binning、ROI 和温度。
- 曝光不同时，只有经过暗电流线性验证才允许缩放。
- 温度和曝光同时严重不匹配时，选择不应用并记录 `DARKCOR=False`。

### 7.3 Flat

- 首选高信噪连续灯/适当暮光 flat，并保持同一光路。
- 检查饱和比例、有效像素比例、照明梯度、相机设置和光谱特征污染。
- LED 宽连续照明可作为候选 flat，但必须通过质量门。
- 目标附近空白天空适合建立加性 sky；除非有经过验证的构造方法，不能直接当
  乘性 pixel flat。

### 降级输出

缺失某项时继续并不等于完成。FITS 必须写 `BIASCOR/DARKCOR/FLATCOR=False`，
JSON 和报告必须列出缺失项。

## 8. 第 3 页：二维几何、天空与一维提取

### 8.0 提取前光学质量门

- 用点源标准星或窄线点源绘制空间 FWHM-波长曲线，不能只报告一个全谱中值；
- 若宽度随波长系统性变化，标记 `OPTALIGN=WARNING` 并优先检查 M2 镜架角度、
  光栅托架倾角和最佳 Y；移动 M2 电机只能重新对焦，不能代替角度调整；
- 若谱线出现重复单侧肩部，先在原始单帧和灯谱中确认，再检查 M1 彗差、狭缝
  照明、最佳 Y、M2/光栅调整与入射光路；不得直接命名为 ghost；
- 标准星与目标的 trace Y 应同时显示。若不在同一实测合格区，响应曲线仍可作为
  探索性降级，但不得把标准星 LSF 或色相关狭缝损失直接转移给目标；
- 未建立 `optimalTraceY` 时允许继续提取，但工程和报告必须标记
  `OPTIMAL_Y_NOT_CALIBRATED`。

### 8.1 几何层级

**A 级：完整二维 rectification**

- 用 arc/flat 的窄线和狭缝边缘拟合色散倾斜、smile、空间弯曲；
- 在重采样前保存原始坐标变换和插值核；
- 同步变换 variance 和 mask。

**B 级：沿曲线迹线提取（当前常用降级）**

- 不把整幅图强制拉直；
- 分箱寻找空间峰，稳健多项式跟随 trace；
- 每个色散列独立定义 aperture 与天空窗口；
- 对历史脏数据更稳健，代价是不能声称完整几何校正。

**C 级：人工 aperture**

- 自动 trace 低置信或目标太弱时，使用参考星/手工中心和宽度；
- 必须在 2D overlay 中确认整段不跑出孔径。

### 8.2 配准与叠加

1. 先检测是否存在重新获取造成的多个稳定组。
2. 空间方向用谱迹剖面配准；色散方向只有结构和相关置信度足够才移动。
3. 使用非循环平移，边缘填 mask/NaN。
4. 先按曝光时间归一，再 sigma clip 和 median/weighted combine。
5. 对不同夜次先独立提取，再在一维波长轴叠加。

### 8.3 天空

- 两侧窗口必须离目标 PSF 足够远，又不能跨过明显照明梯度。
- 宽缝、Bortle 5 和暗弱目标应报告目标/天空比例。
- 强天空线应在二维和离迹 1D 中单独显示。
- 后续版本优先加入二维 B-spline 天空与背景敏感性对照。

### 8.4 提取

- 主路径：Horne86 optimal extraction。
- 对照：相同掩膜和天空下的 boxcar。
- 若 optimal 相对 boxcar 峰值或噪声异常放大，则拒绝 optimal 并降级。
- 输出 uncertainty 和 mask，不能只输出平滑曲线。

## 9. 第 4 页：波长标定

### A 级：Arc + Atlas

1. arc 必须与目标具有相同光栅、狭缝、ROI、binning 和相机安装。
2. 提取 arc 或建立 2D line map。
3. 找峰后与 Ne/Ar/Relco 等线表匹配。
4. 检查最少匹配线、像素覆盖比例、RMS 和严格单调性。
5. 残差图必须显示所有采用/拒绝的线。

### B 级：人工已知线对

- 手工点击确认的 pixel/Å 点写入 `.astroproj`；
- 至少覆盖两端和目标科学波段；
- 多项式阶数不得超过信息量；
- 保留点表、系数顺序、空气/真空定义和残差。

### C 级：标准星模板

- 使用多条 Balmer/恒星吸收线与 ISIS/公共模板匹配；
- 自动方向复核；
- 恒星径向速度、线宽、混合和狭缝照明会移动零点；
- 只能标为 stellar-template 或 transferred solution。

### D 级：已有解转移

只有设备预设完全相同且用天空/已知线复核零点后才能采用。仅凭图像宽度相同不够。

### E 级：无参考

输出像素轴，状态 `NEEDS_REFERENCE`。提取仍有价值，但不得伪造 wavelength/WCS。

## 10. 第 5 页：响应、消光、归一化与二级光谱

### A 级：绝对流量

- 分光光度标准星；
- 大气消光和 airmass；
- 仪器响应；
- 标准物理流量表；
- 输出明确物理单位和不确定度。

### B 级：临时相对响应

- 普通标准星观测/恒星模板比值；
- 屏蔽恒星吸收线并做平滑响应；
- 只能用于相对形状，`ABSFLUX=False`；
- 标准星和目标必须核对狭缝、光栅、M2 焦点、`opticalAlignmentId` 和 trace Y；
  trace Y 不同且最佳像散区未知时，额外标记 `RESPONSE_GEOMETRY_MISMATCH`。

### C 级：仅归一化

- 没有可靠响应星时保留 counts；
- 用稳健分箱、低阶样条/多项式拟合连续谱；
- 保护宽发射线、吸收带和端部低信噪区；
- 同时保留未经归一化的一维谱。

### 二级光谱

- 6800 Å 是当前保守警戒估计，不是实测截止点；
- 数据不直接裁切；
- 记录 `not_tested / suspected / measured`；
- 用同配置热星与冷星响应比、二阶 Balmer 标记或截止滤镜对照实测起点。

## 11. 第 6 页：科学分析

### 通用原则

1. 先定义科学问题，再决定平滑、连续谱和积分窗口。
2. 参考谱必须卷积到近似相同分辨率并使用相同归一化。
3. 峰值、质心、等效宽度和模型线流量不是同一个量。
4. 宽线/混合线优先做多分量模型，不用最高像素代替物理线流量。
5. 同时报告统计不确定度和校准/天空系统误差。

### H-beta/Fe II 示例

- 幂律或局部连续谱；
- Fe II 模板；
- H-beta 窄分量；
- H-beta 两个宽分量；
- [O III] 4959/5007 固定理论比；
- 可选 He II；
- 天空 [O I] 5577 和其他残差单独建模/掩膜；
- 保存模型、残差、窗口和所有先验。

## 12. 第 7 页：交付与归档

每次可复现交付至少包括：

- 标准 FITS：显式 wavelength、flux、uncertainty、mask；
- CSV：便于第三方人工检查；
- PNG：2D 原图/预处理、trace、alignment、wave residual、response、final 1D；
- JSON：输入帧、接受/拒绝、质量门、警告、算法版本和产物路径；
- `.astroproj`：整个操作状态；
- PDF/Markdown：结论、限制、降级等级和待同行复核问题。

### 最终目录与命名

统一采用 `output/Target/YYYY-MM-DD/`，每晚固定包含：

- `final/spectrum.fits`、`spectrum.csv`、`spectrum.png`；
- `diagnostics/`、`calibration/`、`metadata/`；
- 诊断试验和历史运行集中放入 `output/_internal/`，不得与正式产品并列。

运行 `tools/organize_outputs.py` 可重建图形索引和统一交付层。跨夜对比应放在
`output/Target/comparisons/Date-A_vs_Date-B/`，并明确是否只能比较归一化线型。

### 最终人工批准清单

- [ ] 原始文件未改写；
- [ ] 每个自动修复均可追溯；
- [ ] 所有校准兼容性有依据；
- [ ] trace 和天空窗全波段可视检查；
- [ ] 标准星/目标 trace Y 与每块光栅最佳 Y 已核对；
- [ ] 空间 FWHM-波长曲线和谱线左右翼检查完成；
- [ ] M2 电机焦点与 M2 镜架角度没有被混为同一参数；
- [ ] optimal 与 boxcar 没有异常矛盾；
- [ ] 波长线数/覆盖/RMS/零点复核完成；
- [ ] 响应等级和绝对/相对标签一致；
- [ ] 二级光谱状态明确；
- [ ] 归一化没有吞掉目标宽线；
- [ ] FITS/CSV/PNG/JSON 能重新打开；
- [ ] 报告明确列出缺失素材和禁止外推的结论。

## 13. 常见故障决策表

| 现象 | 先检查 | 降级/处理 |
|---|---|---|
| trace 跳到坏点 | 稳健空间剖面、mask、手工中心 | 分组叠加或人工 aperture |
| 多帧位置相差很大 | 是否重新获取、跨夜、设备移动 | 分组处理，勿强行一个 shift |
| 谱线在读出边界断裂 | 原始 2D、拍摄段、Header、同目标互相关 | 只按已验收逐文件清单修复并重建全部派生产品；原始 FITS 保持只读 |
| 标准星线顺序反向 | 当晚方向、相机重装 | 水平翻转所有同组 light/flat/arc |
| arc 不可用 | 曝光、线表、方向、光栅配置 | 标准星模板或像素轴 |
| flat 让结果更差 | 饱和、NaN、灯谱结构、设置不匹配 | 自动质量门拒绝 flat |
| Horne 异常尖峰 | variance/mask/trace profile | 与 boxcar 对照并回退 |
| 空间 FWHM 随波长持续增加 | M2 镜架角度、光栅托架倾角、最佳 Y | 暂停精细线型分析；做窄线灯 FWHM-波长扫描后复调 |
| 谱线出现重复单侧左/右肩 | 原始单帧、窄线灯、M1 彗差、狭缝照明、最佳 Y | 先标为非对称 LSF；未作物理验证前不得自动“去鬼像” |
| 标准星与目标 trace Y 相差明显 | 同光栅最佳 Y、导星位置、目标是否延展 | 响应降级并标记几何不匹配；重拍同 Y 标准星优先 |
| 两侧子孔径氖线分成两条 | M2 纵向焦点、温度、机械回差 | 用 M2 电机使双线重合；随后复查蓝绿红三段 |
| H-beta 看起来弱 | 同口径连续谱、天空、Fe II、参考历元 | 报告复合区，不直接声称本征变弱 |
| 红端异常抬升 | 二级光谱、QE、响应标准 | 保留并标记，做热/冷星对照 |

## 15. NGC 6543 光学状态示例

2026-05-12 同夜 6 张 Vega 单帧均显示空间 FWHM 随波长增加：约 4820 Å 为
8.33-10.58 px，约 5505 Å 为 9.43-12.23 px，约 7077 Å 为 16.36-18.87 px；
合成帧代表值分别为 9.68、11.21、17.73 px。该趋势不是叠加伪影，按 UVEX 官方
判据应优先检查 M2 镜架角度和整体像散状态。

Vega trace 中心约 `Y=769.1`，NGC 6543 约 `Y=724.0`，相差约 45 px；当晚又没有
每块光栅的最佳 Y 记录。NGC 6543 蓝绿端左肩因此应记录为“波长相关非对称 LSF，
疑似 M1 彗差/M2 像散/最佳 Y 共同影响”，而不是已证实的柱面镜-相机窗鬼像。
相关正式谱保持不变，实验性反演只作为 `DIAGONLY=T`、`LSFVALID=F` 的诊断产物。

完整依据见 `20260512-ngc6543-asymmetric-lsf-assessment.md`。
