# ToupSky 处理结果完整性审计

审计日期：2026-08-16  
范围：当前项目中所有以 `<local-data-root>` 为科学输入的正式配置、
运行记录和派生产品。原始 FITS 全程只读。

## 结论

正式结果中没有发现“把多数帧当成绝对正确状态”造成的遗留错误。自动改图现已全局
默认关闭，23 份随项目发布的 TOML 配置也全部明确关闭；需要修复的帧只由逐文件清单
选择。机器审计共检查 18 份 ToupSky 配置、72 张正式输入、20 份运行/验证记录和 3 份
带指纹的派生产品，113 项通过、0 项失败。

辇道增七是本次重点复核对象：A/B 共六帧 Header 状态正常，列边界指标为
−0.15～+0.01，二维谱线连续，四份重跑 manifest 均记录零帧修复。A/B 命名、波长锚点、
B 星 Hα 发射核及清理版 S/N 均保持原结论，不存在被错误移动后“碰巧拟合成功”的情况。
